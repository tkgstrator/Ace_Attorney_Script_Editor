# 立ち絵の仕様（弁護側・検察側・証人）

画像生成 AI（LLM）に立ち絵・背景・机を作らせるときに、そのまま渡すための仕様。
数値は DS 版「逆転裁判 蘇る逆転」の画面を測ったもの（`uv run tools/rom/measure_stands.py` で測り直せる。
手元で取り出したデータから測った数値だけで、絵そのものは含まない）。

この文書は **画面のどこに立つか**（立ち位置ごとの頭の位置・机の高さ）を決める。絵そのもの（キャンバス・色数・輪郭・影・
動きのコマの数と長さ・差分コマの作り方・スプライトシート）は `SPEC.md` に書き、生成した結果は `check.ts` で確かめる。

## 共通

- 画面は **256×192 ドット**。座標は左上が (0, 0)、単位はドット。
- 重ね順は **背景 → 人物 → 机（手前）→ テキストウィンドウ**。
- テキストウィンドウは y=144〜191（半透明の黒）。名前欄はその上の y=132〜143 の左端。
- 人物は **机の上端から 12〜18 ドット下まで** 描けば足りる（DS 版もそこで切れている）。
  それより下は机に隠れて見えない。腰の下まで描いてもよいが、机の上端より上に見える部分が主役になる。
- 頭のてっぺんは **y=17〜31**、頭（髪〜あご）の高さは **約 40 ドット**、頭の幅は **約 45〜55 ドット**（髪を含む）。
- 肩幅は **約 75〜90 ドット**。
- 絵柄: 2000 年代中ごろの DS のアドベンチャーゲーム風のドット絵。1 ドットの輪郭線、3〜4 段のセル影、
  アンチエイリアス・ぼかし・グラデーションなし。人物は透過 PNG。

## 弁護側（defense）

| 項目 | 値 |
|---|---|
| 背景 | 法廷の弁護側の壁。右下に真鍮の柵の柱（ロープ付き）が並ぶ。人物の後ろは板張りの壁 |
| 机 | 上端 **y=148**、画面の左端から **x=0〜205**（右側は柵が見える） |
| 人物の向き | 体を **右** に向ける（画面の右側の検察側を向く） |
| 人物の位置 | 画面の **左寄り**。頭の中心 **x≈75**、頭のてっぺん **y≈18**、体は x 0〜124（肩 x 21〜97） |
| 下端 | y≈159（机の上端から 12 ドット下）まで描く |
| 見え方 | 左肩が画面の左端で切れることがある。机に手をついたり、書類を持つポーズは体が x≈200 まで広がる |

## 検察側（prosecution）

| 項目 | 値 |
|---|---|
| 背景 | 弁護側の背景を **左右反転** したもの（柵の柱は左下） |
| 机 | 上端 **y=148**、**x=50〜255**（弁護側の机の左右反転） |
| 人物の向き | 体を **左** に向ける（弁護側を向く） |
| 人物の位置 | 画面の **右寄り**。頭の中心 **x≈173〜181**、頭のてっぺん **y≈17〜26**、体は x 136〜242（肩 x 157〜239） |
| 下端 | y≈159（机の上端から 12 ドット下）まで描く |

## 証人（witness）

| 項目 | 値 |

## 参考: 裁判長（judge）

- 背景に机（裁判長席）が描かれていて、人物は y≈130 で切れる。頭の中心 x≈127、頭のてっぺん y≈35。

## 生成を頼むときの文例

> 256×192 ドットの画面に置く、DS のアドベンチャーゲーム風のドット絵の立ち絵を、透過 PNG で作ってください。
> 立ち位置は〈弁護側〉。体を右に向け、画面の左寄りに立ちます。頭のてっぺんが y≈18、頭の中心が x≈75、
> 頭の高さは約 40 ドット、肩幅は約 80 ドット。机の上端が y=148 にあり、人物は y≈160 まで描けば十分です
> （それより下は机に隠れます）。キャンバスは 256×192 で、この位置にそのまま置いた状態で出力してください。
