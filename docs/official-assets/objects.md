# 人物・吹き出し・カットイン・重ね絵・サイコ・ロック（OBJ のアニメーション）

[公式の画像アセットの仕様](../official-assets.md) の一部。数値は `tools/assets/official-assets.json` の `games.<作品>.obj`
（計測は `tools/assets/m_obj.py`）。蘇 = 蘇る逆転、2・3 = 逆転裁判 2・3（DS 版）。

## 0. 入れ物（人物のパック）

人物も吹き出しも重ね絵も、data.bin の 1 つの「人物のパック」に入っている（形式は `tools/rom/ex_chars.py`）。

| 項目 | 値 |
|---|---|
| 組の数 | 蘇 281・2 214・3 252（1 組 = 画像 + 動き） |
| 画像 | パレット n 本（16 色 × n、BGR555）+ 部品（OAM 1 個分）ごとの **4bpp** のタイル。部品ごとに 16 ビット単位の RLE で圧縮 |
| 動き | 区間（動き）ごとのコマ送り: コマ・長さ（1/60 秒。0xFF 繰り返し / 0xFE 止まる / 0xFD 消える）・効果音 |
| コマ | 部品の並び（x, y は基準点からの s8、部品の番号、OAM の形・大きさ・パレット） |
| 透明 | 色番号 0（どのパレットでも） |

組の分け方（人物・吹き出し…）は `m_obj.py` の `CATEGORIES`（一覧の絵を見て決めた）と `tables/chars.json`・`tables/anims47.json`。
下の「範囲」は 1 組の中でいちばん大きいコマの、部品を囲む四角。

## 7. 自作するときの目安

- 人物は `tools/sprites/SPEC.md`（256×192 のキャンバス、基準点 (128, 96)、15 色 + 透明、2 本目は特有の動きだけ）。
- 吹き出しは 256×192 の画面いっぱいの 1 枚、11〜15 色。英語版を作るなら同じ大きさで別の絵。
- 重ね絵・小物は 15 色以下、大きさは 8 の倍数。画面の上の位置は「画面の大きさのキャンバスの中で描く」か「(128, 96) を基準点にする」。
- 文字の演出（証言開始など）は色を多めに使ってよい（公式はパレット 8 本）が、1 本 15 色の組に分けられる程度に抑える。
