# 法廷記録・名札・下画面の UI・テクスチャ・フォント

[公式の画像アセットの仕様](../official-assets.md) の一部。数値は `tools/assets/official-assets.json` の
`games.<作品>.record`（`tools/assets/m_record.py`）と `games.<作品>.font`（`tools/assets/m_font.py`）。
蘇 = 蘇る逆転、2・3 = 逆転裁判 2・3（DS 版）。

## 1. 証拠品のアイコンと人物ファイルの顔

上画面の「〜をファイルした」の窓などに出る絵（`record/icon/ja/`）。証拠品と人物ファイルは同じ表・同じ形式で、
台本で人物ファイルとして入れるもの（`record_add profile`・初めから持つ人物）を「顔」として分けた。

| 項目 | 蘇 | 2 | 3 |
|---|---|---|---|
| 証拠品のアイコン | 106 | 71 | 81 |
| 人物ファイルの顔 | 30 | 31 | 39 |
| 大きさ | **64×64**（全部） | 64×64 | 64×64 |
| 形式 | 4bpp、パレット 1 本（32 バイト）を絵ごとに持つ（1 枚 0x820 バイト = パレット 32 + 画素 2048） | 同じ | 同じ |
| 色（証拠品） | 15（12〜15）、最大 15 | 15（15〜15） | 15（14〜15） |
| 色（顔） | 15（14〜15） | 15（14〜15） | 15（14〜15） |
| 透明（色 0）を使う | 証拠品 2.8%、顔 0% | 0% | 0% |

- **ほぼ全部が 64×64 の四角いっぱいに描かれていて、透明の所が無い**（背景の色も絵の一部）。
- 置き方: 上画面の窓で (16, 16) に 64×64、その右に名前 128×16・説明文 128×64（どれも OBJ）。
- 蘇の命令 118 の絵（`record/icon_ds/`、49 枚）は 64×64・9 色（3〜15）で、57% が透明を使う（形を切り抜いた絵）。
- 下画面の一覧で使うのは、同じ大きさ（64×64・16 色）の 3D のテクスチャ（§4）。**小さい別のアイコンは無い**。

## 6. 自作するときの目安

- 証拠品・人物ファイル: 64×64、15 色（パレット 1 本）、四角いっぱいに描く（透明を使わない）。上画面と下画面で同じ絵を使ってよい。
- 名札: 48×16、6〜7 色。名前・説明文は字を絵にせず、プレイヤーのフォントで描いてよい（公式の大きさ 128×16・128×64 の枠に収める）。
- 下画面の UI: 4bpp の OBJ の大きさ（8〜64 の組み合わせ）に合わせ、1 部品 11 色以下。
- 文字: 16×16 のマス・送り 14・行 18。字は 1 色で描き、色は描くときに替える。
