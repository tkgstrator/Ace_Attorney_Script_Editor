# 公式の BGM・効果音の番号（蘇る逆転）

シナリオの `bgm:` / `se:`（文中の `[bgm …]` / `[se …]`）には、DS 版の音の名前（SDAT の名前。`BGM013`・`SE010` など）を
そのまま書ける。プレイヤーは、手元で取り出した音（DS（原音）`assets/extracted/sound/ncsf/` か DS（互換）`assets/extracted/sound/rendered/`、
[公式の章を遊ぶ](../official-chapters.md)）があればそれを鳴らし、無ければ鳴らさない。自作の章でも公式の音で遊べるように、ここに番号と役割の対応をまとめる。

- **役割の出どころ:** 変換済みの 蘇る逆転 第1話（`assets/extracted/converted/ep1.yaml`）で、その番号が使われている場面から読んだもの。
  音を聞いて確かめたものではない（「推定」と書いたものは、場面から推し量ったもの）。
  各番号の音は試聴ページ（`assets/extracted/sound/rendered/index.html`）で聞ける。
- **役割の名前（`trial`・`gavel` など）** はサンプルの仮の音の名前（[演出の使い方](effects.md#効果音の役割)）。
  公式の番号で書いた章は、音を取り出していない手元では無音になる。
- 使い方の例は [サンプル事件「仮面の奇術師」](../../apps/player/cases/masked.yaml)。

## BGM

| 番号 | 場面（第1話での使われ方） | 書く所 |
|---|---|---|
| `BGM023` | 冒頭の事件の場面（プロローグ） | 話の最初のシーン |
| `BGM008` | 開廷前の控え室（「地方裁判所　被告人第2控え室」のカードの直後） | 控え室のシーン |
| `BGM013` | 開廷（木槌の直後）。閉廷の前の裁判長の言葉 | 開廷・場を静めた後・判決の前 |
| `BGM010` | 証言と尋問（1 曲目） | 証言の直前 |
| `BGM011` | 証言と尋問（2 曲目。話の後半の証言） | 後半の証言の直前 |
| `BGM004` | 矛盾を言い切るところ（「ムジュンしています」） | 正しいつきつけの後 |
| `BGM002` | 証人を問いつめるところ（文中で切り替え） | 決定的な矛盾で押しこむ所 |
| `BGM003` | 真犯人を追いつめるところ（文中で切り替え） | 真犯人を名指しする所 |
| `BGM020` | 閉廷後の控え室（勝訴の後） | 後日談 |
| `BGM024` | 推定: 千尋が「いよいよ本番よ」と声をかける所。尋問に入る前の、気を引きしめる曲 | ― |

- 公式は BGM を切り替える前に `bgmPause: true` で一度止めることが多い（止めて空気を変える。[演出の使い方](effects.md#bgm)）。
- 判決の大きな文字（`banner: 無罪`）の前後は、BGM を止めて木槌だけにする（第1話は判決の後、控え室で `BGM020`）。

## 効果音

| 番号 | 役割 | 一緒に書くもの |
|---|---|---|
| `SE010` | 木槌 | `shake: 10`・`strength: 1`。2〜3 回続けることも多い |
| `SE013` | 傍聴席のざわめき | 長い `wait`（60〜120）→ 木槌 →「静粛に！」 |
| `SE019` | 衝撃（驚き・動揺） | `flash`・揺れ（強さ 1） |
| `SE01E` | 衝撃の変化形（矛盾を言い切る台詞の中など） | `[flash]`・`[shake 30 0]` |
| `SE026` | 衝撃の変化形（うろたえる・ど忘れする心の声など） | `[flash]`・`[shake 30 1]` |
| `SE050` | 強い衝撃（証人が崩れる・叫ぶ） | 揺れ（強さ 2 のことも） |
| `SE022` | ライフが減る（`penalty` でエンジンが鳴らす。書かなくてよい） | ― |
| `SE009` | 証拠品を加えたとき、詳細の窓がすべりこむ音（`give` でエンジンが鳴らす。書かなくてよい。`tables/engine.json` の `item_slide_se`） | ― |
| `SE007` | つきつけたときの音（`tables/engine.json` の `present_se`。今はエンジンが鳴らしていない） | ― |
| `BGM014` | 気づき・新事実のジングル（**`se:` で鳴らす**） | `flash`。揺れとは組まない |
| `BGM017` | 驚きのジングル（**`se:` で鳴らす**） | `flash`・揺れ（強さ 0〜1） |

- `BGM014`・`BGM017` は名前が BGM でも短い音で、公式は `se:` で鳴らしている。
- 文字送り（`SE003` 男・`SE004` 女・`SE01A` タイプライター）とページ送り・選択肢の音（`SE005`・`SE000`・`SE001`）はエンジンが鳴らす
  （`apps/player/src/official-audio.ts` の `ALIASES`）。シナリオには書かない。
- 「異議あり！」「待った！」「くらえ！」の声も、吹き出しと一緒にエンジンが出す。
