# 探偵パートの書き方

探偵編（`kind: investigation` の編）を書くエージェント向けの手順書。1 から 9 の順に進めば、公式 3 作の型と決まり文句を使って
1 つの探偵編を書ける。台詞より先に設計を置き、各章は「この段階で決めること → 残す設計メモ → 例 → 点検項目」の順に書いている。

## 章立て

| 章 | ファイル | 中身 |
|---|---|---|
| 1〜3 | [design.md](design.md) | この捜査で何を知るか・証拠と情報の開示順（ミスリードと回収）・場所と人物と進行条件（日時・場所のカード、到着、移動の解放） |
| 4〜6 | [flow.md](flow.md) | 調べる（観察・掛け合い・発見・再調査）・話す・つきつける |
| 6（任意） | [psyche-lock.md](psyche-lock.md) | サイコ・ロック（逆転裁判2・3 の型） |
| 7〜9 | [progress.md](progress.md) | 法廷記録と通知・再訪と捜査の終わり（法廷へのつなぎ）・会話と演出と完成例の点検 |
| 一覧 | [phrases.md](phrases.md) | 決まり文句の一覧と出現回数 |

共通の資料: 事件設計メモの書式（[../README.md](../README.md#事件設計メモの書式)）・文字数の決まり（[../text-length.md](../text-length.md)）・
失敗と直し方（[../pitfalls.md](../pitfalls.md)）。YAML の書き方の細部は [../../scenario.md](../../scenario.md#場所探索編)。
別の事件（時計塔）で書いたひな形と、驚き・気づきなどの小さな演出の並びは [../templates-investigation.md](../templates-investigation.md)。

凡例（**傾向**・**推奨**・**制約**・**実例**）と、1 ページ 2 行 × 16 字・間は手で置く・演出は台詞の直前、の決まりは
裁判パートと同じ（[../trial/README.md](../trial/README.md#書き分けの凡例)）。

## 探偵パートのらしさ

1. **主人公と助手のかけ合いで進む（推奨）。** 調べる所の反応は「主人公の心の声 1 + 助手の相づち 1」が基本の 4〜6 ページ。
   証拠品にならない所こそ、2 人の性格を見せる場にする。
2. **決まり文句は法廷より少ない（傾向）。** 手続きが無いので、定型句は証拠品の知らせ・何もない所の反応・日時のカードくらい
   （[phrases.md](phrases.md)）。その分、人物ごとの口ぐせ（[../../characters/README.md](../../characters/README.md)）でらしさを出す。
3. **次の一手を心の声で示す（推奨）。** 総当たりにならないように、話題・調べる所の最後で「次はどこへ・だれに」を言う。

## 全体の流れ

| 段 | 誰が話す | 演出の定番 | 決まり文句 | 詳しく |
|---|---|---|---|---|
| 日時・場所のカード | （カード） | フェードイン（74%）→ カード（43%）→ BGM（61%） | 同日　某時刻 | [design.md](design.md#3-場所と人物と進行条件) |
| 到着 | 主人公・助手 → その場の人物 | 場所の曲。初めてのときだけ紹介 | 心の声で人物の名前と立場 | [design.md](design.md#到着) |
| 調べる | 主人公の心の声・助手 | 証拠品の所だけ気づきの音 + フラッシュ | 手がかりになるものはない。 | [flow.md](flow.md#4-調べる) |
| 話す | 主人公 ↔ 相手 | 話題の頭で相手の動きを替える | （無し。人物の口ぐせで） | [flow.md](flow.md#5-話す) |
| つきつける | 主人公 → 相手 | 小窓は出さない（エンジンが出す） | あの。これなんですけど‥‥ | [flow.md](flow.md#6-つきつける) |
| 移動の解放 | 主人公の心の声・助手 | 無し | ○○に行ってみよう。 | [design.md](design.md#移動の解放) |
| 証拠品の入手 | 主人公の心の声 → 知らせ | 気づきの音 + フラッシュ → `give` → 青字の知らせ | 証拠品《○○》を法廷記録にファイルした。 | [progress.md](progress.md#7-法廷記録と通知) |
| 日の終わり | 主人公・助手 | BGM を止める → フェードアウト | （今はまだ、証拠が足りないのかもしれない） | [progress.md](progress.md#捜査の終わり) |
| 法廷へのつなぎ | 主人公の心の声 | フェードアウト → 法廷編のカード | 地方裁判所　被告人第○控え室 | [progress.md](progress.md#法廷へのつなぎ) |

## 規模の目安

**傾向**（[../numbers/structure.md](../numbers/structure.md)・[../numbers/volume.md](../numbers/volume.md)）: 1 つの探偵編は台詞
1,130〜1,870 ページ前後、場所 8 前後、1 か所に話題 3〜4（1 つ 15 ページ前後）と調べる所 6〜7（1 か所 4〜6 ページ）、
そのうち証拠品は 1〜2。サイコ・ロックは 1 話に 2〜3。

**推奨:** 規模は目安で、ノルマではない。手に入れるものと知らせる情報の数から、場所と話題の数を決める（[../pitfalls.md](../pitfalls.md)）。

## 例の場所と、足す設定

例は [../trial/README.md](../trial/README.md#例の人物と証拠品) の事件「港の倉庫」の、法廷の前の探偵編。
場所は 3 つ: 港の第3倉庫（夜警の倉田）・留置所の面会室（被告人の港）・夜警の詰め所。
人物と証拠品は裁判パートと同じで、サイコ・ロックのために次を足す。

```yaml
psycheLock: { keys: [magatama], heal: 40 }
evidence:
  magatama: { name: 勾玉, description: ウソを隠す心の錠が見える。 }
flags:
  unlocked: false       # 倉田のサイコ・ロックを外したか
start:
  scene: inv_start
  evidence: [badge, magatama]
gameover: guilty
```
