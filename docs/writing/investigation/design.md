# 1〜3. 何を知るか・開示順・場所と人物と進行条件

台詞を書く前に決めること。書式は [../README.md](../README.md#事件設計メモの書式) の事件設計メモで、裁判パートの対応表
（[../trial/design.md](../trial/design.md#3-証言と矛盾の設計)）の「事前に分かること」の列を、ここで手に入れる形にする。

## 1. この捜査で何を知るか

**決めること**

- 次の法廷編で要る証拠品・人物ファイル・事実を並べる（対応表の「事前に分かること」「正解の操作」から逆算する）。
- この探偵編の終わりにプレイヤーが持っている疑い（「倉田が何か隠している」など）。
- 探偵編の目的を 1 文で（助手との会話で最初に言わせる）。

**設計メモ（例）**

| 次の法廷で要るもの | 手に入る所 | 何のために |
|---|---|---|
| 《入館記録》（外から開いたのは 10時半だけ） | 倉庫の扉の記録装置を調べる | 証言1 の隠れた文を崩す |
| 《ライト》（棚の下、夜警の印） | 倉庫の棚の下を調べる | 証言2 を崩す |
| 倉田が 10時半に入り、ライトを落とした | 倉田のサイコ・ロック | 証言2 の前提（ライトは 10時半から中） |
| 《手袋》（床の油） | 詰め所を調べる | 山場のつきつけの要求 |

**点検:** 次の法廷の対応表のすべての行について、「事前に分かること」がこの探偵編で手に入るか。

## 2. 証拠と情報の開示順

**決めること**

- 真相から逆算して、プレイヤーが知る順を決める。**解答の前提は、その解答を求める前にそろえる。**
- **ミスリードと回収:** 「事実」と「解釈」を分けて、最初にそう考える理由・先に出す違和感・解釈を変える決め手と、それぞれを出す場所を書く。
- 同じ情報を 2 か所で出さない（再訪で同じ発見をくり返さない）。

**設計メモ（例）**

| 順 | 場所・行動 | 知ること | ミスリードと回収 |
|---|---|---|---|
| 1 | 倉庫に着く | 倉田は事件の目撃者 | 倉田は協力的に見える（先入観） |
| 2 | 倉庫: 扉の記録装置 | 外から開いたのは 10時半、夜警用のカード | 「倉田が見回りで開けた」と思わせる違和感（見回りは 11時からのはず） |
| 3 | 倉庫: 棚の下 | 夜警の印のライト | 倉田は「知らない」と言う（ウソの手がかり） |
| 4 | 面会室: 港の話 | 港は 10時前に帰った | 検察の「港の指紋」を、荷運びなら当然と読み替える決め手 |
| 5 | 倉庫: サイコ・ロック | 倉田は 10時半に入り、ライトを落とした（でも「すぐ出た」と言い張る） | 「すぐ出た」は法廷で崩す（手袋） |
| 6 | 詰め所 | 床の油のついた手袋 | 法廷の山場まで意味を伏せる |

**点検:** 各行の「知ること」が、法廷の対応表のどの行に使われるかを言えるか。使われない情報は、人物を見せるための会話として短くする。

## 3. 場所と人物と進行条件

**決めること**

- 場所の数と、それぞれにいる人物（`person`。条件で変えるなら `[{ id, when }]`）。
- 最初に行ける場所（2〜3 か所）と、場所が増える条件（`move` の `when`）。
- 探偵編を出る条件（必要な証拠品・ロックの解除）。

**設計メモ（例）**

| 場所 | 人物 | 行ける条件 | 手に入るもの |
|---|---|---|---|
| 港の第3倉庫（`souko`） | 倉田 | 最初から | 《入館記録》《ライト》・ロックの解除 |
| 留置所 面会室（`menkai`） | 港 | 最初から | 港の話 |
| 夜警の詰め所（`tsumesho`） | ― | 倉田の話題「倉庫のカギ」を聞いた後 | 《手袋》 |
| 地方裁判所（`court_gate`） | ― | 《手袋》を持っている。中で、ロックを外したかを確かめる | 法廷編へ |

**点検:** `bun run check 章.yaml` で、手に入らない証拠品・行けない場所・外さないまま残るロックが無いか（**制約**:
ロックを外さないまま `end` に着く道があるとエラー）。

### 日時・場所のカード

- **制約:** `card` は画面を暗くし、緑の文字を中央寄せでタイプライターの音と出す。台詞と同じ 16 字 × 2 行。
- **傾向:** 1 行目は「○月○日　午後○時○分」。同じ日の続きは「同日　某時刻」（公式のカードで最多の 202 回）か
  「同日　午前○時○分」、日が変わって時刻を伏せるなら「○月○日　某時刻」（117 回）。2 行目は「施設　部屋」の順の場所の名前。
  置く所は探偵編の頭（編の最初のシーンの 43%）と、**場所に初めて来たとき**（探偵パートのカード 436 のうち 259 が場所の `enter` の中。
  [../numbers/phrases.md](../numbers/phrases.md)）。日が変わるときは必ず出す。
- **傾向（並び）:** 探偵編の頭は「フェードイン（74%）→ カード（43%）→ BGM（61%）」（[../numbers/openings.md](../numbers/openings.md)）。
  その後、助手と「今日やること」を 2〜5 ページで確かめ、`investigate` で探偵メニューへ。

**実例:** 場所に初めて来たときのカード（公式は全角空白で区切る）。

> 出典: 逆転裁判3 第2話（留置所に初めて来たとき）

```yaml
- card: "同日　某時刻\n留置所　面会室"
```

```yaml
inv_start:
  - card: "10月2日 午後3時\n港の第3倉庫"
  - fade: in
  - bgm: investigation
    frames: 30
  - sayo: "ここですね、[wait 8]\n事件が起きた倉庫って。"
  - naruse: "（夜警の倉田さんが、[wait 10]\n　ミナト君を見たという場所だ）"
  - investigate: souko
```

### 到着

- **制約:** 場所の `enter` は来るたびに実行する。初めてのときだけの会話は `if: not visited(場所)` で包む。
- **推奨:** 初めてのときは、その場の人物の登場 → 主人公の心の声で名前と立場の紹介 → 相手のあいさつ 1〜3 ページ。
  2 回目からは何も言わせないか、1 ページのあいさつだけ。初めて会った人物は、ここで `giveProfile` する（公式は知らせの文を出さない）。
- **傾向:** 場所ごとに曲がある（探偵パートの BGM の切り替えの 6 割はここ。[../effects.md](../effects.md#bgm)）。

```yaml
souko:
  name: 港の第3倉庫
  person: kurata
  enter:
    - bgm: souko
    - if: not visited(souko)
      then:
        - kurata: "おや、[wait 8]弁護士さんですか。\nご苦労なこってす。"
        - naruse: "（夜警の倉田さん。[wait 10]\n　この事件の目撃者だ）"
        - giveProfile: kurata
```

### 移動の解放

- **推奨:** 最初に行ける所は 2〜3 か所。新しい場所は、話題を聞く・証拠品を手に入れると行けるようにし、行けるようになった所で
  主人公の心の声か助手が行き先を言う（「○○に行ってみよう。」の形は 10 話）。
- **傾向:** 条件つきの移動は 0〜65%（[../structure.md](../structure.md#探偵編の流れ)）。
- **制約:** `move` の `name` の一覧はボタンで、15 字まで（[../text-length.md](../text-length.md)）。探偵編を出るのは、
  場所の行動のブロックの中の `goto` だけ。

```yaml
menkai:
  name: 留置所 面会室
  person: minato
  enter:
    - bgm: menkai
    - if: not visited(menkai)
      then:
        - card: "同日 某時刻\n留置所 面会室"
        - minato: "[speed 4]弁護士さん‥‥。[wait 12]\nオレ、どうなるんすか。"
        - naruse: "（港 健太くん。[wait 10]\n　ぼくの依頼人だ）"
        - giveProfile: minato
  talk:
    - id: minato_night
      topic: あの夜の行き先
      then:
        - minato: "倉庫には、[wait 8]\n10時前に荷を置いただけっす。"
        - minato: "扉の指紋？[wait 10]毎日、\n荷を運んでるんすから。"
        - naruse: "（指紋があるのは[color red]当然[color blue]か。\n　[wait 8]検察の根拠がひとつ崩れた）"
  move:
    - souko
    - to: tsumesho
      when: seen(key)
```
