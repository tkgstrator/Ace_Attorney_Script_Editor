# 4〜6. 調べる・話す・つきつける

探偵メニューの 3 つの行動の書き方。場所 `souko`（港の第3倉庫）を例に、1 つの場所の YAML を行動ごとに分けて載せている
（[探偵パートの設計](design.md#到着) の `enter` とつなぐと 1 つの `souko` になる）。

## 4. 調べる

**決めること:** 1 か所の調べる所（**傾向:** 6〜7、そのうち証拠品は 1〜2。1 か所の反応は中央 4〜6 ページ）と、
それぞれが観察・掛け合い・発見・再調査のどれか。

| 種類 | 書き方（推奨） |
|---|---|
| 観察 | 主人公の心の声 1 で、見たものを言う。事件に関係なくても、場所の空気や人物の暮らしが分かる一言にする |
| 掛け合い | 心の声 1 + 助手の相づち（ツッコミ）1〜2。2 人の性格を見せる |
| 発見 | 気づきの音 + フラッシュ（揺らさない）→ 要の語を赤 → `give` → 知らせ（[法廷記録と通知・捜査の終わり](progress.md#7-法廷記録と通知)） |
| 再調査 | 2 回目は `if: not has(証拠品)` の `else` で、1 ページの短い反応にする（同じ発見をくり返さない） |

- **何もない所（`examineDefault`）:** **傾向:** 公式は主人公の「手がかりになるものはない。」（10 話）の 1 ページ。
  **制約:** 書かなければエンジンの既定（「特に気になるものはない。」）が出る。
- **意味のある所:** 心の声で「後で役に立ちそうだ」と言い、次の行動のヒントにする。

**実例:**

> 成歩堂「手がかりになるものはない。」（蘇る逆転 第2話）

```yaml
souko:
  examine:
    - id: drum
      name: ドラム缶
      area: [8, 96, 56, 72]
      then:
        - naruse: "（ドラム缶が倒れている。[wait 10]\n　床に油が広がっているな）"
        - sayo: "すべりそう‥‥。[wait 8]\n足もと、見てくださいね。"
    - id: door
      name: 扉の記録装置
      area: [200, 60, 32, 40]
      then:
        - if: not has(log)
          then:
            - naruse: "（カードで扉を開けると、[wait 10]\n　記録が残る仕組みか）"
            - se: discover
            - flash: true
            - naruse: "（あの夜は[color red]10時半[color blue]に1度だけ。\n　[wait 8]夜警用のカードだ‥‥）"
            - give: log
            - say: null
              text: "[speed 5]証拠品《入館記録》を\n法廷記録にファイルした。"
              color: blue
          else:
            - naruse: "（扉の記録装置だ）"
    - id: floor
      name: 棚の下
      area: [120, 150, 40, 24]
      then:
        - if: not has(lamp)
          then:
            - naruse: "（棚の下に、[wait 8]\n　何か転がっている‥‥）"
            - se: discover
            - flash: true
            - naruse: "（[color red]ライト[color blue]だ。[wait 12]夜警の印‥‥\n　電池が外れている）"
            - give: lamp
            - say: null
              text: "[speed 5]証拠品《ライト》を\n法廷記録にファイルした。"
              color: blue
          else:
            - naruse: "（ライトが落ちていた所だ）"
  examineDefault:
    - naruse: 手がかりになるものはない。
```

**点検:** 証拠品の所の 2 回目が、1 ページの短い反応になっているか。発見の心の声が、法廷での使い道まで言い切っていないか。

## 5. 話す

**決めること:** 1 か所の話題（**傾向:** 3〜4。1 つ 15 ページ前後。[構成の集計](../numbers/structure.md)）と、
話題が増える条件。

- **話題の出し方（推奨）:** 最初は 1〜2 話題。聞き終えると次の話題が出る（`when: seen(話題ID)`）。証拠品を手に入れる・
  つきつける・別の場所で話を聞くと増える（`when: has(...)` やフラグ）。
- **話題の名前（制約）:** ボタンに収まる 13 字まで（話した印と重ならない）。**推奨:** 7〜10 字の名詞句。
- **中身の型（推奨）:** 主人公の問い → 相手の答え 3〜6 ページ（人物の口ぐせを出す）→ 主人公の心の声で要点をまとめる。
  話題の最後に「次にやること」を言うと、総当たりにならない。
- **演出（傾向）:** 探偵パートは人物の入れ替えが少なく、同じ人物の動き替えが 100 ページに 55〜69 回と多い
  （[演出の使い方](../effects.md#探偵パート100-台詞あたり)）。話題の頭で相手の動きを替える。

```yaml
souko:
  talk:
    - id: night
      topic: 事件の夜のこと
      then:
        - naruse: "倉田さん。[wait 8]あの晩、\n何を見たんです？"
        - kurata: "11時の見回りでね。[wait 10]扉の前に\n男が立っとったんですわ。"
        - kurata: "照らしてみりゃ、[wait 10]\nあの若いのの顔でして。"
        - naruse: "（見回りは11時。[wait 10]\n　扉の記録とくらべたいな）"
    - id: key
      topic: 倉庫のカギ
      when: seen(night)
      then:
        - kurata: "カギのカードは、[wait 8]詰め所に\nしまってありますよ。"
        - naruse: "（カギは詰め所に‥‥。[wait 10]\n　よし、詰め所に行ってみよう）"
```

**点検:** 話題の最後の心の声で、次の行き先か、くらべるものが分かるか。1 つの話題が、別の話題と同じ情報をくり返していないか。

## 6. つきつける

**決めること:** 核心の証拠品への反応・人物ファイルへの反応（だれとだれの関係を見せるか）・見当違いの反応。

- **核心の証拠品（推奨）:** 相手が動揺する（揺れ + 早口）→ 新しい話題や、法廷の伏線になる一言。
- **人物ファイル（傾向）:** 逆転裁判2 から、その人物をどう思っているかの短い会話（2〜4 ページ）が増え、探偵パートのつきつけの
  反応の 7〜8 割になった（証拠品 204〜283・人物ファイル 756〜965）。人物同士の関係を見せる場にする。
- **主人公の切り出し（傾向）:** 「あの。これなんですけど‥‥」（8 話）のように、主人公が 1 ページで差し出してから相手が答える形が多い。
- **見当違い（`presentWrong`）:** 公式には決まった文は無く、人物ごとに 1 つの反応を使い回す。その人らしい一言で返し、
  探偵パートではペナルティを付けない。**制約:** 書かなければエンジンの既定（「特に反応はなかった。」）。
- **制約:** 探偵パートでは、つきつけても「くらえ！」は出ない。証拠品 ID と人物 ID が同じものは `present` に書けない。
- サイコ・ロックは任意の節 [サイコ・ロック](psyche-lock.md)。

**実例:**

> 成歩堂「あの。これなんですけど‥‥」（逆転裁判2 第2話）

```yaml
souko:
  present:
    lamp:
      - naruse: "あの。[wait 8]\nこれなんですけど‥‥"
      - kurata: "そ、[wait 6]そいつは‥‥！"
      - shake: 30
      - kurata: "[speed 2]い、[wait 6]いや、[wait 8]\n見たこともありませんな！"
      - naruse: "（今、[wait 8]明らかに顔色が変わった）"
    minato:
      - kurata: "ああ、[wait 8]あの若いの。\n毎晩、荷を運んどりましたな。"
  presentWrong:
    - kurata: "はあ。[wait 10]\nわしには、よう分かりませんな。"
  move:
    - menkai
    - to: tsumesho
      when: seen(key)
```

**点検:** 動揺の反応が、法廷の前に真相を言い切っていないか（崩すのは法廷の役目）。人物ファイルの反応が、ほかの話題のくり返しになっていないか。
