# 失敗と直し方

裁判パート・探偵パートを書き終えたら、この表で読み直す。どれも「公式らしく見せようとして」起きやすい失敗。

## よくある失敗

| 失敗 | 見分け方 | 直し方 |
|---|---|---|
| 演出の毎ページ盛り | フラッシュ・揺れ・効果音が 3 ページ続けて付く。揺れ 2 が 1 つの法廷編に何度もある | 演出は山場（新しい事実・動揺・決定的な一撃）だけに付ける。**傾向:** 演出の付く台詞は 21〜35%、揺れ 2 は揺れの 1 割前後（[演出の使い方](effects.md)） |
| 証言が長く、争点が散る | 1 つの証言に、つきつけられそうな文が 2 つ以上ある。文が 2 行に収まらない | 1 証言で崩す矛盾は 1 つ。ほかの文は、ゆさぶりで新しい事実を出す文にする。1 文は 16 字 × 2 行（[文字数の決まり](text-length.md)） |
| ゆさぶりが言い直しになる | 証人の答えが、証言の文をくり返すだけ | ゆさぶり 1 つにつき、新しい事実か、証人の人柄が 1 つ出るようにする。何も出ないゆさぶりは 3〜4 ページで切る |
| ヒントが解答になる | `loop` や心の声が、証拠品の名前と文を両方言ってしまう | 段階を分ける: `after` は「何とくらべるか」、`loop` は「どの文が気になるか」、惜しい反応は「話題は近い」。書き終えたら、1 つの証言の `after`・`loop`・ゆさぶり・誤答をまとめて読み、答えが 2 か所以上で言われていないかを見る |
| 口ぐせだけの人物 | どの台詞も語尾で見分けるしかない | 口ぐせは台詞の一部に。その人が何を守りたいか（隠したいこと・見栄・職業の誇り）を、ゆさぶりの答えに出す（[人物の話し方](../characters/README.md)） |
| 主人公が先に全部解く | 心の声が、プレイヤーがつきつける前に矛盾を説明してしまう | 心の声は「引っかかる」までにとどめ、言い切るのはつきつけの後。気づきの演出も、つきつけの後に置く |
| 別解を罰する | 筋の通る別のつきつけにペナルティが付く | 対応表の「別解」の列を埋め、筋の通るものは `present` に足して正解にする（[裁判パートの設計](trial/design.md#3-証言と矛盾の設計)） |
| 探偵パートが総当たり | 次に何をすればよいか分からず、全員に全部をつきつけることになる | 話題・調べる所の最後で、次の行き先を心の声で言う。場所は 2〜3 か所から開き、少しずつ増やす（[探偵パートの設計](investigation/design.md)） |
| 再訪で同じ発見をくり返す | 証拠品を手に入れた所を 2 回目に調べても、同じ発見の台詞が出る | `if: not has(証拠品)` で包み、2 回目は 1 ページの短い反応にする（[調べる・話す・つきつける](investigation/flow.md#4-調べる)） |
| 水増し | 公式の規模に合わせるための証言・話題・くり返しがある | 規模の数は目安で、ノルマではない。事件に要る矛盾と情報の数から、証言と場所の数を決める |

## 機械のチェック（案）

今あるもの: `bun run check`（書き方・詰み・たどり着かないもの）、`--check-font`（フォントに無い字）、`--check-fit`（枠に収まらない文）、
`bun tools/analysis/check-quotes.ts`（公式の文との一致）。次のものは、あると便利な案（まだ無い）。

| 案 | 見るもの | 注意 |
|---|---|---|
| 表示ページ数 | 話・編・シーンごとのページの数（自動のページ分けを含む） | 分母を集計（[文量の集計](numbers/volume.md)）と同じ「重複を除いた台詞」にそろえる |
| 証言の文数・ゆさぶりの長さ | 1 証言の文の数、1 つのゆさぶりのページ数 | 公式の幅（[構成の集計](numbers/structure.md)）の外にあるものを、見直す場所として出す |
| 演出の密度と偏り | 100 台詞あたりの揺れ・フラッシュ・効果音、揺れ 2 の数、演出の続くページ | [演出の集計](numbers/effects.md) と同じ数え方にする |
| 通知の重複 | 同じ証拠品の知らせが 2 回出る道、知らせの形（「ファイルした」「挟んだ」）の混在 | 分岐ごとに写された同じ知らせは 1 つに数える |
| 口調の取り違え | 一人称・呼び方・語尾が、人物の決めた話し方と違う台詞 | 下の「口調の統計の読み方」 |
| 対応表と到達状態の照合 | 設計の対応表のつきつけが、その時点で持てる証拠品か・必要な話題を聞いた後か | 整合性チェックは持てるかまで。プレイヤーが理由を知っているかは対応表で見る |

- どれも数値はノルマではなく、見直す場所の目安にする。

## 口調の統計の読み方

[人物の話し方](../characters/) の話し方の数は、次の点に気をつけて使う。

- **役割ごとに違う。** 同じ人物でも、検事・被告人・証人のときで話し方が変わる（例: 御剣は検事の話と被告人の話で違う）。
  書く人物の今の役割に近い話の数を見る。
- **割合の分母に注意。** 糸鋸の「文末の 1 字の 48% が『ス』」は、語尾を数えた文のうちの割合で、「台詞の 48% に『ッス』が入る」
  という意味ではない。語尾の数え方は [人物の話し方](../characters/README.md) の説明を読む。
- 口ぐせを割合どおりに入れると、かえって不自然になる。場面の緊張（動揺・告白）で口ぐせが崩れるのも公式の型。
