# 演出の使い方

数の出どころは [numbers/effects.md](numbers/effects.md)（頻度・内訳・効果音と BGM の場面）と
[numbers/patterns.md](numbers/patterns.md)（並びの型）。演出の回数は YAML に書かれた回数で、同じ数え方の台詞 100 ページあたりで比べる。

## 頻度

### 探偵パート（100 台詞あたり）

| 演出 | 蘇る逆転 | 逆転裁判2 | 逆転裁判3 |
|---|---|---|---|
| 揺れ（ステップ / 文中） | 13.9 / 7.3 | 8.4 / 4.3 | 19.1 / 11.5 |
| フラッシュ（ステップ / 文中） | 18.8 / 10.5 | 10.9 / 6.7 | 26.4 / 17.8 |
| 効果音（ステップ / 文中） | 16.1 / 4.6 | 11.6 / 4.2 | 23.9 / 8.9 |
| BGM の切り替え | 2.8 | 3.0 | 3.3 |
| BGM の一時停止 / 再開 | 2.7 / 1.0 | 2.5 / 1.1 | 2.7 / 1.4 |
| フェードアウト | 3.1 | 2.4 | 3.1 |
| 人物を入れ替える show | 46.6 | 44.5 | 43.8 |
| 同じ人物の動きを替える show（ステップ / 文中） | 55.0 / 5.4 | 69.4 / 3.1 | 60.3 / 11.6 |
| 証拠品の小窓 | 8.0 | 9.8 | 13.7 |
| 日時・場所の表示（card） | 1.1 | 1.3 | 0.8 |

読み取れること:

- **法廷は探偵より派手。** 揺れ・フラッシュ・効果音は法廷のほうが 1.2〜1.6 倍多い（逆転裁判3 はどちらも多い）。
- **逆転裁判2 は控えめ、逆転裁判3 は派手。** 逆転裁判2 の揺れとフラッシュは他の半分ほど。逆転裁判3 は文中の演出
  （文中の show・se）が特に多く、1 ページの中で表情と音を細かく変える。
- **立ち絵は 1 ページに 1 回以上動く。** 法廷では人物の入れ替え 70 + 動き替え 50〜60 で、100 ページあたり 110〜130 回。
  探偵パートは人物の入れ替えが少なく（話し相手が決まっている）、同じ人物の動き替えが多い。
- **BGM は 100 ページに 2〜3 回しか切り替えない。** その代わり一時停止（無音にする）が法廷で 4 回ある。
  曲を替えるより、止めて空気を変えるほうが多い。

## 強さ・長さ・色

- **揺れの強さ:** 蘇る逆転 0: 52%・1: 42%・2: 6%／逆転裁判2 1: 77%・2: 17%・0: 6%／逆転裁判3 0: 46%・1: 42%・2: 13%。
  強さ 2 は 1 割前後で、とっておきの所だけ。
- **揺れの長さ:** 30 フレーム（既定）が 84〜91%、10 フレームが 9〜16%。10 フレームは木槌と一緒の短い揺れ。
- **フラッシュ:** 3 作とも 100% 白。色つきのフラッシュは使わない。
- **フェードアウトの色:** 黒 78〜87%、白 13〜22%（回想や、場面を大きく変える所）。
- 文中の揺れは強さ 0〜1 が中心（蘇る逆転 0: 67%、逆転裁判3 0: 48%・1: 37%）。

## 効果音の役割

効果音の番号は作品ごとの名前で、音そのものは確かめていない。どんな演出と一緒に鳴るかから、役割を推し量った。
（「フラッシュと」などは前後 2〜3 ステップの中にある割合）

| 役割（推定） | 蘇る逆転 | 逆転裁判2 | 逆転裁判3 | 一緒に出る演出 |
|---|---|---|---|---|
| 気づき・新事実（ハッとする短い音） | BGM014 | BGM014・SE054 | BGM014・SE054 | フラッシュ 64〜86%、揺れは少ない |
| 衝撃（驚き・動揺） | BGM017・SE019 | SE019 | SE019 | フラッシュ 54〜89%、揺れ（強さ 1）60〜70% |
| 衝撃の変化形 | SE01E・SE026・SE024・SE050・SE022 | SE01E・SE026・SE024・SE022 | SE01E・SE026・SE024・SE050・SE022 | フラッシュと揺れが 6〜7 割 |
| 木槌 | SE010 | SE010 | SE010 | 揺れ（強さ 1・10 フレーム）98〜100%、法廷だけ、続けて 2〜3 回 |
| 傍聴席のざわめき | SE013 | SE013 | SE013 | 傍聴席の絵（overlay）と長い wait、法廷だけ。この後に木槌が来る |
| 検事の吹き出しの声 | SE00E | SE06C | SE046 | 吹き出し 76〜100% |

- 効果音のステップの 2〜4 割は文中（`[se ...]`）に書かれている。台詞の途中の決め所で鳴らす。
- 「気づき」の音は揺れと組まない（揺れと一緒になるのは 2〜6%）。「衝撃」の音は揺れと組む。
- このエンジンの手書きのシナリオでは、音の ID は役割で名付けるとよい（`se: discover`・`se: gavel`・`se: damage` は
  [apps/player/src/sounds.ts](../../apps/player/src/sounds.ts) にある）。衝撃・ざわめきなど無いものは、`shock`・`murmur` のような
  名前で書いておき、音を用意したときに鳴るようにする。

## BGM

| 場面 | 蘇る逆転 | 逆転裁判2 | 逆転裁判3 |
|---|---|---|---|
| 証言を聞く所 | BGM010（40）・BGM011（12） | BGM072（40）・BGM073（13） | BGM119（34）・BGM120（20） |
| 場所に来たとき | 場所ごとの曲（BGM031・001・012・025 など） | 同じく（BGM031・065・012・068） | 同じく（BGM112・012・031・109） |

- **証言の曲は 2 曲に決まっている。** 1 曲目が 6〜8 割で、2 曲目は話の後半の証言や、追いつめられた証人の証言。
- **場所には曲が付いている。** 探偵パートの BGM の切り替えの 6 割は「場所に来たとき」（`enter`）。
- 法廷で BGM を切り替える直前は、シーンの頭・フェードの直後（場面の転換）が最も多く、次に木槌（SE010 + 揺れ）の後、
  「気づきの音 + フラッシュ + 主人公の台詞」の後（反撃に移る所）。

## 吹き出し

- 弁護側の「異議あり！」（つきつけ）・「待った！」（ゆさぶり）・「くらえ！」（つきつけの要求）はエンジンが自動で出すので、
  YAML に `shout` を書くのは**相手が割り込む所**だけ。公式でも YAML に書かれた吹き出しの 7 割以上は検事のもの
  （蘇る逆転: 御剣 53%・狩魔 豪 23%／逆転裁判2: 狩魔 冥 30%・御剣 27%・亜内 16%／逆転裁判3: ゴドー 24%・狩魔 冥の「待った」24%）。
- 吹き出しは「フラッシュ + 効果音 + 吹き出し」の並びで出る（台詞の直前の演出の 2% 前後）。

## 並びの型

### 台詞の直前の演出

台詞の 30%（蘇る逆転）・21%（逆転裁判2）・35%（逆転裁判3）に、直前（前の台詞より後）の演出が付く。その組み合わせ:

| 組み合わせ | 蘇る逆転 | 逆転裁判2 | 逆転裁判3 | 使いどころ |
|---|---|---|---|---|
| フラッシュ + 効果音 | 17.5% | 19.8% | 21.7% | 気づき・新事実・証拠品を示す |
| フラッシュ + 効果音 + 揺れ 1 | 16.1% | 18.1% | 14.7% | 驚き・動揺（ふつうの強さ） |
| フラッシュ + 揺れ 0 | 14.2% | - | 5.2% | 軽い驚き（音なし） |
| フラッシュ + 効果音 + 揺れ 0 | 8.9% | - | 9.4% | 軽い驚き（音あり） |
| BGM 一時停止 | 5.4% | 9.3% | 5.1% | 空気が変わる・重大な告白の前 |
| フェードアウト + イン | 5.2% | 5.7% | 4.4% | 場面の転換 |
| フラッシュ + 効果音 + 揺れ 2 | 2.5% | 3.0% | 4.9% | 決定的な一撃・崩れ落ちる |
| フラッシュ + 効果音 + 吹き出し | 2.0% | 2.3% | - | 割り込みの「異議あり！」 |

文中では「flash + se + shake」（決め台詞の途中で一撃）が最も多く、「flash だけ」「flash + se」「shake だけ」が続く（蘇る逆転は「flash + shake」も多い）。

### 正しいつきつけの後

証言の `present` から移った先のシーン（ほとんどが正しいつきつけ）の、はじめの 16 個の演出・台詞に現れるもの:

| 演出 | 蘇る逆転（80 件） | 逆転裁判2（54 件） | 逆転裁判3（127 件） |
|---|---|---|---|
| フラッシュ | 96% | 93% | 89% |
| 効果音 | 84% | 91% | 92% |
| 揺れ | 89% | 39% | 80% |
| パン | 84% | 93% | 82% |
| 証拠品の小窓（出す / 消す） | 71% / 71% | 76% / 74% | 71% / 62% |
| BGM 一時停止 | 66% | 35% | 9% |
| BGM の切り替え | 14% | 44% | 9% |

定番の流れ（エンジンが「異議あり！」を自動で出した後）:

1. BGM を止める（蘇る逆転で 3 分の 2）。
2. 主人公が 1〜3 ページで矛盾を指摘する。証拠品の小窓を出し、要の語を赤字にする。小窓は 2 ページほどで消す。
3. パンで証人（か検事）へ。「気づき」か「衝撃」の音 + フラッシュ + 揺れ（強さ 1〜2）で、相手が動揺する。
4. 裁判長が受ける。ここで BGM を「追いつめる曲」に替えることがある（逆転裁判2 で 44%）。

### つきつけの要求（demand）の正解の後

効果音 78〜88%、フラッシュ 71〜84%、証拠品の小窓 63〜83%、揺れ 47〜74%、BGM 一時停止 34〜55%。
正しいつきつけの後とほぼ同じ並びで、パンが少ない（36% 前後。同じ相手と話し続けるため）。

### ペナルティの前後

- 直前はほぼ必ず裁判長の台詞（2〜3 ページ）。「主人公の言い訳 1 ページ → 裁判長 2 ページ」の形も多い。
- 蘇る逆転では、ペナルティの直後に「フラッシュ + 揺れ → 主人公の心の声 → フェードアウト」が続く。
- 入る所は見当違いのつきつけ（`wrong`）が 58〜76%。ほかは選択肢の誤り 5〜12%、つきつけの要求の誤り 7〜13%、
  特定の証言への的外れなつきつけ 1〜16%、ゆさぶりの中の選択 2〜6%。

### ゆさぶり

- はじめは「主人公の台詞 → パン → 証人の台詞」（ゆさぶりの頭の 6〜7 割）。エンジンが「待った！」を自動で出した後に、
  主人公が 1 ページ問いただし、パンして証人が答える。
- 1 つのゆさぶりは 8〜10 ページ（蘇る逆転 中央 7〜8）。90% で 13 ページまで。
- 途中で検事が割り込む（吹き出し）・新しい事実が出る（気づきの音 + フラッシュ）こともある。

### 証拠品の小窓

小窓を出してから消すまでの台詞は、中央 2（25〜75%: 1〜3、90%: 5）。1〜3 ページだけ見せて消す。

## オリジナルを書くときのおすすめ

- 演出は**台詞の直前**に置き、1 ページに 1 つの組み合わせまで。強い組み合わせ（揺れ 2）は 1 つの法廷編で数回に抑える。
- 驚きの強さを 3 段で使い分ける: 軽い（フラッシュ + 揺れ 0）・ふつう（フラッシュ + 衝撃の音 + 揺れ 1）・
  決定的（フラッシュ + 衝撃の音 + 揺れ 2、ときに BGM を止める）。
- 気づき（新しい事実・証拠品）は「気づきの音 + フラッシュ」で、揺らさない。
- BGM は替えるより止める。重大な告白・正しいつきつけの直後は `bgmPause: true`、場面が落ち着いたら `bgmPause: false`。
- 立ち絵は、台詞 1〜2 ページごとに動きを替える（`show` の talk / idle）。感情が変わるページでは文中の `[show ...]` で替える。
- 具体的な並びは [templates-trial.md](templates-trial.md) と [templates-investigation.md](templates-investigation.md)。
