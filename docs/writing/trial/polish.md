# 8. ページと演出の仕上げ

筋と台詞がそろった後に、ページの切り方・間・色・演出を整える。ここで足すのは読みやすさと山場の強弱で、筋は変えない。

**決めること:** 法廷編の山場（強い演出を当てる所）を 3〜5 か所に絞る。
**点検:** `bun run check --check-font --check-fit 章.yaml` が警告なしか。演出の続くページが 3 ページ以上ないか。

## ページ

- **制約:** 1 ステップ = 1 行 16 字 × 2 行。超えると自動で次のページに分かれる（[../text-length.md](../text-length.md)）。
- **推奨:** 文の終わりでページを切る（**傾向:** 読点で終わるページは 1〜2%）。改行は文節の切れ目か、1 行目で 1 文を言い切る所
  （[../typography.md](../typography.md#改行の位置)）。長い話はステップを分け、同じ人物に 2〜3 ページまで続けて言わせる。
- **傾向:** 1 ページの字数は中央 20〜22 字。16 字いっぱいの行は 8% で、詰めすぎない。

## 間と速さ（文中コマンド）

| 所 | 推奨 | 傾向 |
|---|---|---|
| 読点の後 | `[wait 10]`〜`[wait 16]`（ためを作りたい読点だけ） | 「、」の後の wait は中央 12 フレーム |
| 句点・「！」・「‥‥」の後（ページの途中） | `[wait 16]`〜`[wait 30]` | 中央 16〜20 フレーム |
| ページの最後 | 置かない（ページ送りで止まる） | ― |
| ためらい・重い話 | 台詞の頭に `[speed 4]`〜`[speed 6]`、途中で `[speed 3]` に戻す | speed の 3〜4 割は台詞の頭で遅くする |
| 叫び・驚きの第一声 | `[speed 2]` | 速くするのは 13〜19% |
| 沈黙 | `[speed 8]‥‥‥‥` の 1 ページ | 「‥‥」は 100 字に 3〜3.7 回 |

数の出どころは [../typography.md](../typography.md) と [../numbers/typography.md](../numbers/typography.md)。

## 色

- 青（心の声）は「（」で始めると自動で青になる（**制約**）。2 行目は全角空白で下げる（**傾向:** 99〜100%）。
- 赤は 1 ページに 1 かたまり、2〜6 字（**傾向:** 中央 4 字）。証拠品・時刻・矛盾の要の語だけ。`[color white]`（心の声なら `[color blue]`）で戻す。
- 緑は電話・無線・画面の外の声で、台詞全体を `say` の `color: green` にする。

## 演出

- **推奨:** 演出は台詞の直前に置き、1 ページに 1 つの組み合わせまで。驚きは 3 段（軽い: フラッシュ + 揺れ 0／ふつう: フラッシュ + 衝撃の音 +
  揺れ 1／決定的: フラッシュ + 衝撃の音 + 揺れ 2、ときに BGM を止める）。気づきは「気づきの音 + フラッシュ」で揺らさない。
- **傾向:** 台詞の 21〜35% に直前の演出が付く。BGM は替えるより止める（一時停止が法廷で 100 台詞に 4 回）
  （[../effects.md](../effects.md)）。
- **推奨:** 立ち絵は 1〜2 ページごとに `show` の talk / idle で動きを替え、感情が変わる字で文中の `[show ...]` を使う。
- 並びの型（驚きの 3 段階・気づき・沈黙・回想）の YAML は [../templates-investigation.md](../templates-investigation.md#小さな演出の並び)。

## 仕上げの点検

| 点検 | 方法 |
|---|---|
| フォントに無い字 | `bun run check --check-font 章.yaml`（エラー。言い換えは [../../katakana.md](../../katakana.md)） |
| 枠からのはみ出し | `bun run check --check-fit 章.yaml`（警告） |
| 詰み・たどり着かない所 | `bun run check 章.yaml` |
| 演出の盛りすぎ | 揺れ 2 の数、3 ページ以上続く演出を目で数える（機械のチェックの案は [../pitfalls.md](../pitfalls.md#機械のチェック案)） |
| 公式の文との一致（docs に載せるとき） | `bun tools/analysis/check-quotes.ts ファイル` |
