# 6. ヒント・誤答・ペナルティ

プレイヤーが詰まらず、しかも答えを言われずに済むようにする仕組み。対応表の「ヒントと誤答反応」の列
（[裁判パートの設計](design.md#3-証言と矛盾の設計)）を、ここで台詞にする。

**決めること:** 証言ごとに、ヒントを何段に分けるか（何とくらべる → どの文 → 惜しい所）・惜しいつきつけ・ペナルティの量。
**点検:** 1 つの証言の `after`・`loop`・ゆさぶり・誤答の反応をまとめて読み、答え（文と証拠品の組）が 2 か所以上で言われていないか。

## ヒントの段階

| 置き場所 | 誰が | 言うこと（推奨） |
|---|---|---|
| 証言の後（`after`） | 主人公の心の声 | 何とくらべるか（証拠品の名前か、法廷記録）。どの文かは言わない |
| 尋問の一巡（`loop`） | 助手（**傾向:** 心の声も 18〜46%） | 気になる文を指す。答えの証拠品は言わない |
| ゆさぶりの答え | 証人 | 新しい事実を少しずつ出す。隠れた文への入り口 |
| 惜しい反応 | 裁判長・心の声 | 「話題は近いが、ここではない」と示す |
| つきつけの要求の問い | 裁判長 | 証拠品の性質を言う（「〜を示す証拠品」） |

- **推奨:** 同じ証言の中で、段階が進むほど具体的にする。`loop` は、一巡したプレイヤーだけが聞く所なので、`after` より一歩踏み込んでよい。
- 例: [一問分の完成例](example.md#証言) の `t1`（`after` は「記録とくらべる」、`loop` は「扉の前で何をしていたか」）。

## 誤答

- **見当違いのつきつけ:** 話の中で 1 つ（`defaults.wrongPresent`）を使い回し、要所だけ証言ごとの `wrong` で上書きする。
- **惜しいつきつけ:** 文の `present` に、その証拠品だけの反応を書く（[ゆさぶり・つきつけ](cross.md#追加の証言と言い直し) の `t2` の《入館記録》）。
- **別解は罰しない（推奨）:** 同じく筋の通るつきつけは正解にする。罰するのは筋の通らないものだけ。

証言ごとの `wrong` の例（`defaults.wrongPresent` の代わりに、検事に嫌みを言わせる）:

```yaml
- naruse: "こ、[wait 8]これです！"
- himuro: "[speed 4]‥‥弁護人は、[wait 10]\n夜警の話を聞いていたのか？"
- judge: "[speed 4]‥‥ペナルティを与えます。"
- penalty: true
- naruse: "（[speed 4]うう‥‥。[wait 12]\n　照らした、という所だ）"
```

## ペナルティ

- **傾向:** 入る所は見当違いのつきつけ（58〜76%）が最多。ほかは特定の文への的外れなつきつけ・つきつけの要求の誤り・
  選択肢の誤り・ゆさぶりの中の選択（[構成の集計](../numbers/structure.md#ペナルティの入る所yaml-の入れ物)）。
- **並び（傾向）:** 主人公の苦しい言い訳 1 ページ → 裁判長の叱責 2〜3 ページ → `penalty` → 主人公の心の声で反省。
  蘇る逆転では、ペナルティの直後に「フラッシュ + 揺れ → 心の声」。
- **制約:** `penalty: true` は `defaults.penalty` の量だけ減らし、ダメージの音をエンジンが鳴らす。0 になると `gameover` のシーンへ。
  ゲージ（`life` が 10 より大きい）のときは、要所の前で `lifeRisk` で減る量を予告できる（`penalty: risk` で予告の量）。
- **傾向（ライフ）:** 蘇る逆転は 5 つ（1 回 1 つ）、逆転裁判2・3 は 80 のゲージで、予告の 73% が 16。一発で終わる 80 は最後の山場だけ。
- **決まり文句:** 裁判長の「‥‥ペナルティを与えます。」「弁護人は、もっと慎重に発言してください！」「どう関係するのですかな？」（どれも 14 話）。
  ペナルティの後の主人公の心の声は、心証が悪くなったと嘆く形が定番（14 話）。

**実例:** 見当違いのつきつけの後の、決まった流れ（全話で同じ）。

> 裁判長「弁護人は、もっと慎重に発言してください!」（蘇る逆転 第1話）

> 裁判長「‥‥やむを得ません。弁護人にはペナルティを与えます。」（蘇る逆転 第1話）

> 成歩堂「（‥‥裁判長の心証が悪くなったみたいだ‥‥）」（蘇る逆転 第1話）
