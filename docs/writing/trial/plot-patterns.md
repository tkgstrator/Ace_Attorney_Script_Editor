# 筋の型（公式 3 作の法廷パート）

法廷パートの**筋の組み立て**（だれを、どの順に証言台に立たせ、被告人の疑いがどう深まり、どう晴れるか）を、
公式 3 作の法廷の日をすべて読んで数えたもの。台詞の書き方ではなく、事件の運び方の型。
設計の手順は [裁判パートの設計](design.md)、決着の書き方は [反論から判決まで](climax.md) を参照。

- **材料:** 変換した 蘇る逆転 第1〜5話（法廷の日 12）、逆転裁判2 第1〜4話（7）、逆転裁判3 第1〜5話（8）。
  手元で取り出した台本（[公式の章を遊ぶ](../../official-chapters.md)）を、正解の流れだけ読んだ。
- **読み方:** 数は目安で、ノルマではない（[書き方の分析](../README.md) の凡例と同じ）。人物は [人物の話し方](../../characters/README.md) の ID で書く。

## 全体の流れ（3 作に共通）

```text
開廷 → 冒頭弁論（検察が被告人を疑う根拠）
     → 最初の証人（刑事か、被告人本人か、目撃者）
     → 検察側の目撃者・関係者（ここに真犯人がいることが多い）
     → 証言から出た人物（弁護側が尋問・召喚を求めて増える）
     → 判決寸前まで追いこまれる → 助言・新しい証拠で持ち直す
     → 真犯人の名指し →「証拠がない」「動機がない」で一度詰まる → 最後の 1 つで決着
```

## 1. 被告人がなぜ疑われているか（冒頭）

| 作品 | 冒頭で検察が示す根拠 | 冒頭弁論の中身 |
|---|---|---|
| 蘇る逆転 | 「目撃者がいる」が基本。物証（血文字・指紋つきの拳銃）か状況（被告人しかいない）が付く。動機を正面から示すのは第1話だけ | 検事が根拠を並べる |
| 逆転裁判2 | 「被告人の持ち物が現場に」（メガネ・帽子・ボタン）＋「凶器の指紋」＋密室か目撃 | 宣言だけ。中身は最初の証人（刑事）が話す |
| 逆転裁判3 | 状況（現場にいた）＋物証（凶器・毒と指紋）＋動機（金・恨み・恋愛）の 3 点 | 検事の人物を見せる場も兼ねる（動機を弁護側に答えさせる、冒頭弁論を拒む、など） |

- **型:** 根拠は 1 つではなく、**目撃・物証・状況・動機のうち 2〜3 つ**を重ねる。プレイヤーはここで「なぜ被告人が犯人とされているか」を全部知る。
- **動機**は、第 1 話・短い話ほど冒頭で示す（蘇る逆転 第1話、逆転裁判2 第1・4話、逆転裁判3 第1・3・4話）。
- 弁護側は冒頭では反論できない。「尋問で崩す」「証言を聞いてから決めて」と受けるのが精一杯。
- 2 日目以降の冒頭は、**前日に出た疑問への検察の答え**から始まる（「その点は認める。そのうえで…」と筋を替える）。

**実例:**

> 御剣「被告人の有罪は、1点のうたがう余地もないだろう。」（蘇る逆転 第2話 1 日目）

> 須々木マコ「とにかく尋問では、証言のウソを暴くッス!」（逆転裁判2 第1話。冒頭では反論できず、尋問で崩すと受ける）

## 2. 最初の証人

| 作品 | 最初の証人 | 検察が被告人本人を証言台に立たせる |
|---|---|---|
| 蘇る逆転 | 捜査担当の刑事（gumshoe）が 4 日、目撃者が 3 日、被告人が 1 日 | 第1話だけ。動機を確かめ、「現場へ行ったか」でウソを引き出して、目撃者へつなぐ入口 |
| 逆転裁判2 | 4 話とも刑事（事件の概要と物証の説明係） | なし（被告人と話すのは控え室だけ） |
| 逆転裁判3 | 刑事 3 日、被告人 3 日、目撃者・関係者 2 日 | 3 回（第1話、第2話 2 日目、第5話 2 日目）。裁判長が「弁護側に不利だが」と確かめ、弁護側が依頼人を信じて受ける手続きが毎回入る |

- **型:** 最初の証人は「**刑事**（事件の経緯と物証）」か「**被告人本人**（検察が問いただす）」。
- 被告人を先に立たせるときは、被告人の**小さなウソ**（事件の夜のことを隠す）を検察が暴き、「それを見た証人がいる」と
  目撃者につなぐ。依頼人を信じていいのか、と主人公が揺れる場面にもなる。
- **第 1 話（導入の話）**は 3 作とも 1 日で決着し、証人は 2 人（最初の証人 → 真犯人の目撃者）。最初の証人は
  被告人本人（蘇る逆転・逆転裁判3）か刑事（逆転裁判2）。

**実例:**

> 亜内「まず、被告人・矢張くんの話を聞きたいと思います。」（蘇る逆転 第1話。最初の証人に被告人を立たせる）

> 亜内「被告人の尋問だけで有罪判決をいただこう、などと‥‥」（逆転裁判3 第1話。被告人の次に目撃者を出すときの言い分）

## 3. 証人の順と、弁護側が尋問・証人を求める流れ

基本の並びは「**刑事 → 検察側の目撃者・関係者 → 証言から出た人物**」。1 日に 2〜3 人。
3 人目以降は、弁護側（か裁判長・検事）が求めて増える。弁護側が求める型は次のとおり。

| 型 | 中身 | 例 |
|---|---|---|
| 尋問権を主張する | 判決に進みかけた所で「今の発言は新しい証言だ、まだ尋問していない」と止める。検事の説明や証人の言い足しを、証言として尋問させてもらう | 蘇る逆転 第2・4話、逆転裁判3 第2話 |
| 反証の権利 | 証人の主張（有罪の筋書き）に対して「その点について証言を」と求める | 逆転裁判3 第1・4話 |
| 証言に出た人物を呼べ | 証言から新しい人物が出たので、その人を証人に呼ばせる。検察は「崩せなければ有罪を認めろ」の条件を付けることが多い | 蘇る逆転 第2・5話、逆転裁判3 第5話 |
| 話題を指定する・再尋問 | 「まだ証言していないことがある」「○○について証言を」と、同じ証人にもう一度証言させる | 逆転裁判2 第2・4話 |
| 告発して召喚させる | 真犯人と名指しした人物を、裁判長に召喚させる | 逆転裁判2 第4話、逆転裁判3 第2・3話 |

- 「この証人は信用できない」は、弁護側より**検察・裁判長**が口にすることが多い（弁護側寄りの証人を退けようとする）。
  弁護側は「だからこそ尋問させてください」と粘って証言を続けさせる。
- 証人が**隠し事を小出しにする**（聞かれるまで言わない、検事に口止めされていた）ことが、次の証言を呼ぶ仕組みになる。
- 逆転裁判2 は証人がすべて検察の召喚で、弁護側が「証人として申請」する形はない。蘇る逆転・逆転裁判3 は後半ほど弁護側が申請する。

**実例:**

> 成歩堂「ぼくの《尋問》がまだです!」（蘇る逆転 第2話 1 日目。判決に進みかけた所で止める）

> 成歩堂「弁護側は‥‥虎狼死家に対する尋問を要求します。」（逆転裁判2 第4話 2 日目）

> 神乃木「‥‥たとえ証拠がなくても‥‥証言という手がある!」（逆転裁判3 第4話。証拠が尽きて、証言で立証する）

> 裁判長「先ほどの有罪判決は、撤回します!」（蘇る逆転 第4話 2 日目。傍聴席の飛び入りの証言を聞くため）

## 4. 真犯人の位置

| 作品 | 真犯人の位置 | 名指しの時点 |
|---|---|---|
| 蘇る逆転 | ほぼ検察側が呼んだ目撃者・関係者。最終日の早い段で証言台に立つ | 最終日の 1 つ目か 2 つ目の証言を崩した直後 |
| 逆転裁判2 | 最後の日の最後の証人（第1〜3話） | 最後の日の中ほど（休憩の前） |
| 逆転裁判3 | 最後の証人（第1〜4話） | 最終日の中盤 |

- **型:** 真犯人は**検察側の目撃者・関係者の中**にいて、最後の証人になる。被告人を指さす目撃証言そのものが、
  真犯人の偽装であることが多い（なりすまし・偽名・目撃のトリック）。
- 名指しの後、「**証拠がない**」「**動機がない**」「一人では不可能」で 1〜2 段粘られ、最後の一手（証拠品 1 つ・失言を誘う罠）で決着する。
- 例外（話の後半にだけある）: 検事が真犯人（蘇る逆転 第4話の過去の事件、逆転裁判3 第5話）、依頼人が黒幕（逆転裁判2 第4話）、
  前の審理の弁護士（逆転裁判3 第3話）、協力者の顔をした警察の上層部（蘇る逆転 第5話）。**第 1 話では使わない。**

**実例:**

> 姫神「決定的な証拠、ないじゃない。」（蘇る逆転 第3話 3 日目。名指しの後の粘り）

## 5. 疑いが深まる・晴れる流れ

- 1 日のうちに、弁護側の指摘で「晴れる」と検察の反撃で「深まる」が交互に来る。蘇る逆転で 3〜5 回、逆転裁判2 で 3〜6 回、逆転裁判3 で 5〜8 回。
- **検察が弁護側の指摘を逆手に取る**型:

| 型 | 中身 |
|---|---|
| 弁護側の証明が被告人に返る | 弁護側が崩した事実が、別の意味で被告人に不利になる（ウソを暴く＝通りすがりではない証明、アリバイ＝殺人現場にいた証明） |
| 時期のすり替え | 「それは事件の前（後）にできたものかもしれない」 |
| 別の理由の差し込み | 「現場にいたのは○○のため」と、矛盾に別の説明を付ける |
| 立証の責任を返す | 「では死体・凶器はどこへ？」と、弁護側に説明を求める |
| 資料の新旧・後出し | 検察が新しい記録や、隠していた証拠を出す |

- **判決寸前の山:** 毎日 1 回は、裁判長が「弁護側の立証は失敗」と言いかけるところまで追いこまれる。
  **助言役の一言**（蘇る逆転は千尋の声、後の作品は助手の口出し・傍聴席の飛び入り）か、「証拠品を 1 つだけ」の最後のチャンスで持ち直す。
- 大きな反転（事件の見え方が変わる）は、1 つの話に 1〜2 回。現場が変わる、被害者と犯人の立場が入れ替わる、など。

**実例:**

> ゴドー「今日の裁判で、オレたちは‥‥“逆アリバイ”を立証したのさ。」（逆転裁判3 第2話 1 日目。弁護側のアリバイの証明が、殺人現場にいた証明に返る）

> 狩魔冥「弁護側はまだ、何も証明していない!」（逆転裁判2 第2話 1 日目）

## 6. 1 日目の終わり方

- 1 日で決着するのは各作の第 1 話（と逆転裁判3 第4話）。ほかの話の 1 日目は、**判決を出せない理由**を作って持ち越す。
  - 別の容疑者・別の可能性が浮かぶが、確かめられない
  - 被告人ではないと示せたが、ほかに犯人の候補がいない
  - 常識では説明できない証言を無視できない
  - 証人が逃げる・証言を拒む
  - 検察の落ち度で検事が猶予を求める／被告人の爆弾発言で中断する
- 持ち越すときは、裁判長が双方に調べを命じる（弁護側への「宿題」がそのまま探偵パートの目的になる）。

**実例:**

> 裁判長「今の時点で、被告に判決を下すことはできません。」（逆転裁判2 第2話 1 日目）

> 裁判長「しかし!1パーセントのギモンの余地がある!」（逆転裁判2 第3話 1 日目）

> 裁判長「明日までに、その答えを見つけてください。」（蘇る逆転 第3話 2 日目。弁護側への宿題）
- 最終日は期限（最後の審理の日・時効）で延長を封じ、真犯人の証人との一騎打ちで終える。

## 第 1 話（導入の話）を書くときの型

3 作の第 1 話に共通する組み立て。1 日・法廷だけ・証人 2 人。

| 段 | 中身 |
|---|---|
| 控え室 | 依頼人の不安と、師（助手）の励まし。依頼人が事件の夜のことを話す（ただし何かを隠している） |
| 開廷・確認 | 裁判長が被告人の名前・死因などを確かめる（操作の練習を兼ねる） |
| 冒頭弁論 | 検察が**動機＋状況＋目撃者**を示す。被告人が疑われる理由がここで全部そろう |
| 1 人目 | **被告人本人**を検察が問いただし、小さなウソを暴く（か、刑事が経緯と物証を説明する）。「それを見た証人がいる」 |
| 2 人目 | 検察側の目撃者。証言は 2〜3 回。1 回目は易しい矛盾（言いすぎ）、崩れるごとに嘘が深くなる。**この証人が真犯人** |
| 山場 | 判決寸前 → 師の助言で「今の話を証言として尋問させてください」→ 最後の証言 → 名指し → 「証拠がない」→ 決め手 |
| 閉廷後 | 控え室で依頼人と師。事件にまつわる品で締める |

- **助言役（師・助手）は最後まで横にいる。** 操作の説明だけでなく、判決寸前の持ち直し・検察の逆手への立て直し・
  証人の隠し事への気づきで、毎回 1 声かける（蘇る逆転 第1話の千尋が手本。[人物の話し方](../../characters/mia.md)）。
- 検察の逆手（上の 5.）を 1 回入れると、第 1 話でも「勝ったと思ったら追いこまれる」山ができる。
- **法廷で話すのは、裁判長・検事・弁護側（主人公と助手）と、証言台にいる人だけ。** 被告人席の被告人が尋問に割りこむことはない。
  被告人の話は、証言台に立たせる場面（上の「1 人目」）か控え室で聞く。証人の隠し事は、ゆさぶり・証拠品（詳しく調べる）から出す。
