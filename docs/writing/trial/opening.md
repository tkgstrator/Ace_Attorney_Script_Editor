# 7. 法廷の会話（開廷から証言まで）

法廷の手続きの会話。ここは決まり文句でテンポよく進め、事件の中身は冒頭陳述と証人の個性に絞る。
決まり文句の一覧と回数は [決まり文句（裁判パート）](phrases.md)（出どころは [決まり文句の集計](../numbers/phrases.md)）。

**決めること:** 控え室をはさむか・冒頭陳述で出す証拠品・証人の登場の一言（その人の個性）。
**点検:** 手続きの台詞に、事件の説明を詰め込みすぎていないか（冒頭陳述は 2〜4 ページ）。

## 控え室（1 日目の前置き）

- **傾向:** 逆転裁判2・3 の 1 日目は、法廷の前に被告人第○控え室で依頼人・助手と話すことが多い
  （[書き方の型（構成）](../structure.md#法廷編の流れ)）。カードの 2 行目は「地方裁判所　被告人第○控え室」（14 話）。
- **推奨:** 依頼人の不安 → 主人公が励ます → 助手が今日の見どころ（相手の検事・証人）を言う。5〜15 ページ。
  係官が呼びに来るか、主人公の心の声で切り、フェードアウト。

```yaml
court_lobby:
  - card: "10月3日 午前9時42分\n地方裁判所 被告人第2控え室"
  - fade: in
  - bgm: lobby
  - minato: "[speed 4]弁護士さん‥‥。[wait 16]\nオレ、本当にやってないんです。"
  - naruse: "わかってる。[wait 10]\nだから、ぼくがここにいるんだ。"
  - sayo: "今日の検事は、[wait 8]ヒムロ検事。\n手強いですよ、ナルセさん。"
  - kakari: "弁護人！[wait 10]\nまもなく開廷です！"
  - naruse: "（‥‥よし。[wait 12]\n　行こう）"
  - bgm: null
    frames: 30
  - fade: out
  - goto: court_open
```

## 開廷

- **傾向:** 法廷編の始まりは「フェードイン（100%）→ 日時・場所（63%）→ 木槌 → BGM（85%）→ 裁判長」
  （[編の始まりの集計](../numbers/openings.md)）。木槌は効果音 + 短い揺れ（10 フレーム・強さ 1）で、揺れと組むのが 98〜100%。
- **誰が:** 裁判長が開廷を宣言し、検事・弁護士が「準備完了」を答える（順はどちらでもよい）。
- **推奨:** 返事の後に、主人公の心の声で相手の検事を一言評する（今日の相手を印象づける）。

**実例:** 開廷から冒頭弁論の要求まで（元の YAML から、背景・文字の枠・立ち絵の動きの行を省いた）。

> 出典: 蘇る逆転 第2話（法廷1 の始まり）

```yaml
- se: SE010
- shake: 10
  strength: 1
- wait: 40
- bgm: BGM013
- judge: "これより、綾里　真宵の\n法廷を開廷します。"
- edgeworth: "検察側、\n準備完了しております。"
- pan: 2
  to: phoenix
- wait: 30
- phoenix: "弁護側、\n準備完了しております。"
- judge: "御剣検事。[wait 16]\n冒頭弁論をおねがいします。"
```

自作の例（木槌を 2 回続ける形）:

```yaml
court_open:
  - card: "10月3日 午前10時\n地方裁判所 第2法廷"
  - fade: in
  - se: gavel
  - shake: 10
    strength: 1
  - wait: 12
  - se: gavel
  - shake: 10
    strength: 1
  - wait: 18
  - bgm: trial
  - judge: "これより、[wait 10]港 健太の\n法廷を開廷します。"
  - himuro: 検察側、準備完了しております。
  - naruse: 弁護側、準備完了しています。
  - naruse: "（ヒムロ検事‥‥。[wait 12]\n　証拠しか信じない人だ）"
  - goto: court_statement
```

## 冒頭陳述

- **誰が:** 裁判長が「○○検事。冒頭弁論をおねがいします。」（12 話）と促し、検事が事件のあらましを 2〜4 ページで言う。
  最後に証拠品を出し、裁判長が受け取る。
- **証拠品の提出（制約と傾向）:** `give` の直後に、名前なしの青字の知らせ「証拠品《○○》を法廷記録にファイルした。」
  （`say: null`・`color: blue`。公式は `[speed 5]` のやや遅い送り）。`give` で証拠品の詳細も画面の上に出る。
- **演出:** 検事が話し始める所で `show` を検事に。証拠品の説明の間だけ小窓（`showEvidence`）を出し、1〜3 ページで消す。
- **文中コマンド:** 時刻・凶器など要の語を赤（`[color red]`〜`[color white]`）。1 ページに 1 かたまり、2〜6 字。

```yaml
court_statement:
  - judge: "では、[wait 8]ヒムロ検事。\n冒頭弁論をおねがいします。"
  - show: himuro
  - himuro: "事件は10月1日の夜。[wait 12]\n港の第3倉庫で起きた。"
  - himuro: "倉庫の持ち主が、[wait 8]後頭部を\n[color red]殴られて[color white]死んでいた。"
  - himuro: "死亡推定時刻は、[wait 8]\nこの解剖記録のとおり。"
  - showEvidence: autopsy
  - give: autopsy
  - say: null
    text: "[speed 5]証拠品《解剖記録》を\n法廷記録にファイルした。"
    color: blue
  - showEvidence: null
  - judge: "よろしい。[wait 10]\n受理しましょう。"
  - goto: court_witness
```

## 証人の登場

- **誰が:** 検事が「○○を入廷させてください。」（14 話）と呼び、証言台へ。検事が「証人。名前と職業を。」（12 話）と聞き、
  証人が名乗る。名乗りの後に、その人らしい一言（口ぐせ・職業の自慢・緊張）を 1〜2 ページ。
  裁判長が「では、証人。」（12 話）→「証言をおねがいします。」（9 話）で証言に入る。
- **演出:** 呼ぶ台詞の後に `pan` で証言台へ（検察側 → 証言台は `pan: 5`）。証人の最初の台詞の前に登場の動きを `show` で決める。
- **係官:** 裁判長が「係官！」（8 話）と呼んで証人を連れて来させる形もある。係官の台詞は 1〜2 ページの知らせだけ。

**実例:** 検事が名前と職業を聞く形（聞き方は検事ごとに少しずつ違う）。

> 御剣「証人。名前と職業は?」（蘇る逆転 第2話）

> 御剣「‥‥証人。名前と職業を。」（蘇る逆転 第5話）

```yaml
court_witness:
  - himuro: "夜警の倉田 源を\n入廷させてください。"
  - pan: 5
    to: kurata
  - wait: 31
  - himuro: "証人。[wait 12]名前と職業を。"
  - kurata: "倉田 源と申します。[wait 12]\n倉庫街で夜警をしとります。"
  - kurata: "この道40年。[wait 10]倉庫のカギは\nわしの庭みたいなもんでして。"
  - judge: "では、[wait 8]証人。\n証言をおねがいします。"
  - goto: t1
```

## 証言の手続き

- **制約:** 「証言開始」「尋問開始」の帯と、その下の題（`testimony`、16 字まで）はエンジンが出す。証言の文は台詞と同じ 16 字 × 2 行。
- **傾向:** 証言の曲は 2 曲に決まっていて、1 曲目が 6〜8 割（[演出の使い方](../effects.md#bgm)）。`reading` の頭で替える。
- **推奨:** `reading`（最初に聞く所）は `[wait]` 入りの台詞で読ませ、尋問の `text` は同じ文から wait を除いたものにする。
- **証言の後（`after`）:** 裁判長（21〜36%）か検事が受け、主人公の心の声で「どこかに矛盾があるはず」と構える。
  決まり文句は裁判長の「では、弁護人。尋問を。」（10 話）。
- 証言そのもの（どの文を正解にするか）は [裁判パートの設計](design.md#3-証言と矛盾の設計)、完成した一問は [一問分の完成例](example.md)。
