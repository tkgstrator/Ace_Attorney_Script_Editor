# 9. 一問分の完成例と点検

設計メモの 1 行（[裁判パートの設計](design.md#3-証言と矛盾の設計) の証言1）から、証言・ゆさぶり・隠れた文・正しいつきつけの後までを
通して書いた例。事件は自作の「港の倉庫」。もう 1 つの完成例として、別の事件（時計塔）の [法廷パートのひな形](../templates-trial.md)
（《修理票》の一問。隠れた文で初めて矛盾する形に直したもの）も同じ点検を通してある。

## 設計メモ（この一問の分）

| 列 | 中身 |
|---|---|
| 対象の文 | 隠れた文「男は11時に扉を開けて、倉庫へ入っていきました」（`stood` をゆさぶると現れる） |
| 事前に分かること | 扉の記録は外からカードで開けたときに残る（探偵パートで《入館記録》を調べる） |
| 証拠が示すこと | 外から開いたのは午後10時半の 1 度だけ |
| 両立しない理由 | 11時に外から扉を開けて入ったなら、11時の記録が残るはず |
| 正解の操作 | 隠れた文 +《入館記録》 |
| 別解 | 無し（元の文「扉の前に立っていた」は記録と両立する） |
| 指摘後に分かること | 男は入っていない → 証人が言い直す（[ゆさぶり・つきつけ](cross.md#追加の証言と言い直し) の `t2`） |
| ヒントと誤答反応 | `after` で「記録とくらべる」、`loop` で助手が扉の件を指す。誤りは `defaults.wrongPresent` |

## 証言

```yaml
t1:
  testimony: 事件の夜に見た男
  witness: kurata
  reading:
    - bgm: testimony
    - kurata: "あの夜の11時ごろ、[wait 10]\nわしは倉庫を見回っとりました。"
    - kurata: "第3倉庫の扉の前に、[wait 10]\n若い男が立っとったんです。"
    - kurata: "あの背かっこうは、[wait 12]\nそこの被告人に間違いない。"
  statements:
    - id: patrol
      text: "あの夜の11時ごろ、\nわしは倉庫を見回っとりました。"
      before:
        - bgm: cross
      press:
        - naruse: "11時ちょうど、[wait 8]\nですか？"
        - kurata: "見回りは毎晩、[wait 8]11時から。\n決まっとるんです。"
        - naruse: "（時刻は、[wait 8]\n　はっきりしているのか）"
    - id: stood
      text: "第3倉庫の扉の前に、\n若い男が立っとったんです。"
      press:                                # ゆさぶりで隠れた文を引き出す型
        - naruse: "立っていただけ、[wait 8]\nですか？"
        - kurata: "い、[wait 6]いや‥‥。[wait 12]\nそういえば、扉を‥‥。"
        - if: not asked_door
          then:
            - himuro: "証人。[wait 10]見たことは\nすべて話したまえ。"
            - judge: "今の話を、[wait 8]\n証言に加えてください。"
            - set: { asked_door: true }
    - id: door
      when: asked_door
      text: "男は11時に扉を開けて、\n倉庫へ入っていきました。"
      press:
        - naruse: 見間違いでは？
        - kurata: "この目で見ました。[wait 10]\n間違いありません。"
      present:
        log:
          - goto: contra1                   # 正しいつきつけ。「異議あり！」はエンジンが出す
    - id: figure
      text: "あの背かっこうは、\nそこの被告人に間違いない。"
      press:
        - naruse: "顔は、[wait 8]\n見なかったんですか？"
        - kurata: "暗かったですからな。[wait 10]\nでも、背かっこうで分かります。"
  after:
    - judge: "ふむう‥‥。[wait 12]\nでは、弁護人。尋問を。"
    - naruse: "（どこかに[color red]矛盾[color blue]がある。\n　[wait 8]法廷記録とくらべよう）"
  loop:
    - sayo: "ナルセさん、[wait 10]扉の前で\n何をしてたのか、気になりません？"
```

## 正しいつきつけの後

軽い矛盾（話を一歩進めるつきつけ）なので、揺れ 1 で BGM は止めない（並びの型は [ゆさぶり・つきつけ](cross.md#正しいつきつけの後)）。
裁判長が言い直しを命じ、休廷をはさんで次の証言へ（[反論から判決まで](climax.md#休廷)）。

```yaml
contra1:
  - naruse: "証人は、[wait 8]11時に男が\n扉を開けたと言いました。"
  - showEvidence: log
  - se: discover                     # 気づき: 音 + フラッシュ（揺らさない）
  - flash: true
  - naruse: "でも入館記録では、[wait 8]\n外から開いたのは[color red]10時半[color white]だけ！"
  - showEvidence: null
  - pan: 0                           # 弁護側 → 証言台
    to: kurata
  - wait: 31
  - se: shock                        # ふつうの衝撃: 音 + フラッシュ + 揺れ 1
  - flash: true
  - shake: 30
    strength: 1
  - kurata: "[speed 2]う、[wait 6]うぐッ！"
  - shout: objection
    by: himuro
  - himuro: "[speed 4]‥‥フン。[wait 12]証人は\n扉のことを取り違えただけだ。"
  - judge: "証人。[wait 10]\n証言を修正してください！"
  - kurata: "[speed 4]へえ‥‥。[wait 12]\nわしの見まちがいでした。"
  - goto: recess
```

## 点検

| 点検 | この例 |
|---|---|
| 「証言は A、証拠は B、同じ条件で両立しない」と 1 文で言えるか | 言える: 11時に外から入った ⇔ 外から開いたのは 10時半だけ |
| 解答の前提が、解答より前に手に入るか | 《入館記録》は探偵パートで手に入り、法廷へ移る条件に入っている（整合性チェックで確かめた） |
| 元の文へのつきつけで、同じ矛盾が成り立ってしまわないか | 「扉の前に立っていた」は記録と両立する。矛盾は隠れた文で初めて成り立つ |
| 別解 | 無し。ほかの証拠品は `defaults.wrongPresent`（叱責 2 ページ + ペナルティ） |
| ヒントが解答になっていないか | `after` は「記録とくらべる」、`loop` は「扉の前で何をしていたか」。証拠品の名前と文を同じ所で言っていない |
| ゆさぶりが言い直しになっていないか | `patrol` は時刻が確かだという事実、`stood` は隠れた文、`figure` は顔を見ていないという事実が出る |
| 字数 | すべての台詞と証言の文が 16 字 × 2 行（`--check-fit` で警告なし）。題は 8 字 |
| 決まり文句 | 「証言に加えてください」「では、弁護人。尋問を。」「証言を修正してください！」 |
