# 1〜3. 何を覆すか・真相とプレイヤーの知識・証言と矛盾の設計

台詞を書く前に決めること。ここが固まっていないと、ゆさぶり・ヒント・ペナルティがすべてぶれる。
書式は [書き方の分析](../README.md#事件設計メモの書式) の事件設計メモ。例は「港の倉庫」（[裁判パートの書き方](README.md#例の人物と証拠品)）。

## 1. この裁判で何を覆すか

**決めること**

- 検察側の主張を 1 文で書く（「被告人が○時に○○で○○した」）。弁護側はそれのどこを覆すのか。
- この法廷編の終わりの状態（無罪で決着／真犯人を名指しして持ち越し／新しい謎を残して持ち越し）。
- 証言の数（**推奨:** 1 つ目は易しく、崩れるごとに証人の嘘が深くなる。**傾向:** 1 つの法廷編に 5〜7。
  [構成の集計](../numbers/structure.md)）。数は目安で、必要な矛盾の数から決める。水増しの証言は作らない。

**設計メモ（例）**

| 項目 | 港の倉庫 |
|---|---|
| 検察側の主張 | 被告人・港は 10月1日の午後11時に第3倉庫へ入り、持ち主を殴って殺した。夜警の倉田が目撃した |
| 覆すもの | 「11時に港が入った」という目撃（入った記録が無い）→「照らして顔を見た」（照らせない）→ 倉田がその時刻に中にいた |
| 終わりの状態 | 倉田が認め、無罪で決着（1 日で終わる形） |
| 証言 | 2 つ（目撃の証言 → 言い直した証言）＋ 山場のつきつけの要求 1 つ |

**点検:** 検察側の主張と、弁護側の到達点が、それぞれ 1 文で言えるか。

## 2. 事件の真相とプレイヤーの知識

**決めること**

- 実際の時系列（分単位でよい）。だれが、いつ、どこで、何をしたか。
- 証人ごとの認識と隠したいこと。「事実」「思い込み」「意図的なウソ」を分ける。
- プレイヤーがいつ何を知るか（探偵パート・冒頭陳述・証言・ゆさぶり）。**解答の前提は、解答を求める前にそろえる。**

**設計メモ（例）**

| 時刻 | 実際にあったこと | 残ったもの（証拠） |
|---|---|---|
| 午後10時前 | 港が荷を置いて帰る | 扉の港の指紋（荷運びなので当然ある） |
| 午後10時半 | 倉田が夜警用のカードで扉を開けて入る。持ち主と口論 | 《入館記録》（外からカードで開けたときだけ残る） |
| 午後11時すぎ | 倉田が持ち主を殴る。持ち主は倒れてドラム缶を倒し、床に油がこぼれる | 《解剖記録》（死亡推定 11時〜11時半）・床の油 |
| 同じころ | もみ合いで倉田のライトが棚の下に転がり、電池が外れる | 《ライト》（夜警の備品の印） |
| その後 | 倉田は油のついた手袋を詰め所に隠し、中から扉を開けて出る（記録は残らない） | 《手袋》 |
| 午後11時半 | 倉田が「11時に若い男が入るのを見た」と通報 | 目撃証言 |

| 人物 | 事実として知っていること | 思い込み | 意図的なウソ |
|---|---|---|---|
| 倉田（証人） | 自分が殴った | ― | 11時に男が入るのを見た／ライトで顔を照らした／すぐ出た |
| ヒムロ（検事） | 目撃と指紋 | 指紋があるので港が犯人 | ― |
| 港（被告人） | 10時前に帰った | ― | ― |

| 知る所 | プレイヤーが知ること |
|---|---|
| 探偵パート | 《入館記録》（10時半に夜警用のカード）・《ライト》（倉庫の中）・《手袋》（油）。サイコ・ロックで、倉田が 10時半に入ってライトを落としたことを認める |
| 冒頭陳述 | 《解剖記録》（11時〜11時半、ドラム缶を倒した） |
| 証言・ゆさぶり | 「11時に男が扉を開けて入った」（隠れた文）、ライトの電池は毎晩入れ替えている |

**点検:** どの証拠も「いつ・どこで手に入るか」が決まっているか。解答に要る事実が、その解答より前に出ているか。

## 3. 証言と矛盾の設計

**決めること:** 証言ごとに、正解の文と証拠品の対応表を作る。最初の点検は
「**証言は A と言い、証拠は B を示す。同じ条件で両立しない**」と 1 文で書けるか。

| 列 | 書くこと |
|---|---|
| 対象の文 | 証言のどの文か（隠れた文なら、現れる条件も） |
| 事前に分かること（入手箇所） | その矛盾に要る事実と、プレイヤーが知る所 |
| 証拠が示すこと | 証拠品の説明文から言えること |
| 両立しない理由 | 同じ時刻・同じ場所で、両方は成り立たない理由 |
| 正解の操作 | 文 + 証拠品（つきつけの要求なら問いと証拠品） |
| ほかの答え（別解） | 同じく筋の通るつきつけ。あれば正解として受ける |
| 指摘後に分かること | 次の証言・次の展開につながる新しい事実 |
| ヒントと誤答反応 | `after`・`loop`・ゆさぶり・惜しい反応で何を言うか |

**設計メモ（例）**

| 列 | 証言1（`t1`） | 証言2（`t2`） | 山場（`final`） |
|---|---|---|---|
| 対象の文 | 隠れた文「11時に男が扉を開けて入った」（扉の文をゆさぶると現れる） | 「ライトで照らしたら、被告人の顔でした」 | 問い「11時より後に、証人が倉庫の中にいたことを示す証拠品」 |
| 事前に分かること | 扉の記録は外から開けたときに残る（探偵パート） | 倉田のライトは 10時半から倉庫の中（サイコ・ロック） | 油がこぼれたのは持ち主が倒れたとき（解剖記録・床の油） |
| 証拠が示すこと | 外から開いたのは 10時半の 1 度だけ | ライトは棚の下で、電池も外れていた | 詰め所の手袋に、その油 |
| 両立しない理由 | 11時に入ったなら記録が残る | 11時に外で照らせるライトが無い | 11時すぎに中にいなければ油はつかない |
| 正解の操作 | 隠れた文 +《入館記録》 | この文 +《ライト》 | 《手袋》 |
| 別解 | 無し（元の文「扉の前に立っていた」とは両立する） | 無し | 無し |
| 指摘後に分かること | 男は入っていない → 証言の言い直し | 倉田は照らしていない → 倉田がそのとき中にいた疑い | 倉田が認める |
| ヒントと誤答反応 | `loop` で助手が扉の件を指す | 《入館記録》をこの文に出すと「10時半のことは今は関係ない」と惜しい反応 | 誤りは「それが倉庫の中を示すのか」と裁判長 |

- **ミスリード:** 「事実と解釈」を分けて書く。例では、扉の港の指紋（事実）を検察は「犯人の証拠」と解釈する。
  最初にそう見える理由（港は倉庫に出入りしていた）、先に出す違和感（港は「10時前に帰った」と言う）、
  解釈を変える決め手（荷運びなら指紋は毎日つく）を、それぞれどこで出すかを決める。
- **別解は罰しない。** 同じく筋が通るつきつけがあれば、両方を `present` に書いて正解にする。

**点検:** 対応表のすべての行で「両立しない理由」が 1 文で書けているか。「事前に分かること」が、その操作より前に
手に入っているか（整合性チェックは証拠品を持てるかまでは見るが、プレイヤーが理由を知っているかは見ない）。
