# 4. ゆさぶり・追加の証言・つきつけ

証言を崩す操作の書き方。どの文にどの証拠品をつきつけるかは [design.md](design.md#3-証言と矛盾の設計) の対応表で決めてある前提。

**決めること:** 各文のゆさぶりで出す新しい事実（1 つずつ）・隠れた文の有無・言い直しの後の新しい嘘。
**点検:** どのゆさぶりも、言い直しではなく新しい事実か人柄を出しているか。

## ゆさぶり

- **制約:** エンジンが「待った！」を出してから `press` のブロックに入る。終わると次の文へ進む。
- **傾向:** ゆさぶりの頭の 6〜7 割が「主人公 → パン → 証人」。1 つのゆさぶりは 8〜10 ページ（90% が 13 ページまで。
  [../numbers/patterns.md](../numbers/patterns.md)）。検事の割り込み・新しい事実（気づきの音 + フラッシュ）もよく入る。
- **推奨の型:** ①主人公の問い → ②証人の答え（新しい事実を 1 つ）→ ③主人公の心の声か助手の一言で「気になる／関係なさそう」。
  何も出ないゆさぶりは 3〜4 ページで切る。

## ゆさぶりで新しい証言を引き出す型

- **傾向:** 証言の 26〜40% に、ゆさぶりで現れる隠れた文（`when`）がある（[../numbers/structure.md](../numbers/structure.md)）。
- **型:** 主人公がゆさぶる → 証人が言いかけて口ごもる → 検事か裁判長が「すべて話すように」→
  「証言に加えてください」（8 話）→ フラグを立てる → 隠れた文が現れる。隠れた文が正解になることが多い。
- **推奨:** 同じゆさぶりを 2 回目に選んだときのために `if: not フラグ` で包む。矛盾が「隠れた文で初めて」成り立つようにする
  （元の文でも同じ証拠品で崩せるなら、隠れた文は要らない）。例は [example.md](example.md#証言) の `stood`。

**実例:** 求めるのは弁護側のことも、裁判長のこともある。

> 成歩堂「今の証人の発言を、証言に加えてください!」（逆転裁判2 第2話）

> 裁判長「それでは、証言に加えていただきましょう!」（蘇る逆転 第5話）

## つきつけ

- **制約:** 正解の文の `present` に証拠品 ID を書く。エンジンが「異議あり！」を出してからブロックに入る。
  `goto` しなければ同じ文に戻る。見当違いは `wrong`（無ければ `defaults.wrongPresent`）。
- **傾向:** 正解は 1 証言に 1 つ。2 つ以上の文に反応があるのは、別の証拠品で別の方向へ進む作りのとき。
- **推奨:** 別解（筋の通る別のつきつけ）があれば、それも正解にする。惜しいつきつけ（話題は近いがこの文ではない）には、
  その文の `present` に専用の反応を書き、次に見るべき所を示す（[hints.md](hints.md)）。

**実例:** 主人公が矛盾を言い切る決まった形。

> 成歩堂「今の発言は、この証拠品のデータとムジュンしています!」（蘇る逆転 第1話）

## 正しいつきつけの後

- **傾向**（[../effects.md](../effects.md#正しいつきつけの後)）: BGM を止める（蘇る逆転で 3 分の 2）→ 主人公が矛盾を指摘
  （証拠品の小窓 + 赤字、1〜3 ページ）→ 小窓を消す → パンで証人へ → 衝撃（音 + フラッシュ + 揺れ）→ 証人の動揺 →
  検事の割り込み → 裁判長が証言の修正や追加を命じる。
- **推奨:** 話を一歩進めるだけの軽い矛盾は揺れ 1 で BGM を止めない（[example.md](example.md#正しいつきつけの後)）。
  決定的な矛盾は揺れ 2 と BGM の一時停止（[climax.md](climax.md#追い詰め)）。
- **制約:** 検事の割り込みの「異議あり！」だけは YAML に `shout` で書く。

## 追加の証言と言い直し

- **誰が:** 裁判長が「証言を修正してください！」（5 話）か「証言に加えてください」で命じ、証人が言い直す。
- **演出:** 証言の曲を 2 曲目に替える（話の後半や、追いつめられた証人の証言で使う）。
- **推奨:** 前の嘘を認めて、別の嘘に逃げる。正解の文は、前の証言とは別の証拠品で崩れるようにする。
- ゆさぶりの途中に選択肢を出し、「どこを突くか」を選ばせる形もある。誤りにペナルティ（**傾向:** ペナルティの 2〜6% がここ）。

**実例:**

> 裁判長「では、証人。証言を修正してください。」（逆転裁判2 第4話）

## 「異議あり！」「待った！」「くらえ！」の使い分け

| 吹き出し | 意味 | エンジンが自動で出す所（制約） | YAML に `shout` で書く所 |
|---|---|---|---|
| 異議あり！（`objection`） | 相手の言い分に反論する | 尋問のつきつけの直前 | 検事・相手の割り込み。主人公が尋問の外（会話の中）で反論する所 |
| 待った！（`hold`） | 相手の言葉を止める | 尋問のゆさぶりの直前 | 相手が主人公の話を遮る所。主人公が判決・閉廷を止める所 |
| くらえ！（`takethat`） | 証拠品を突きつける | 法廷のつきつけの要求（`demand`）の後 | ほぼ書かない（公式の YAML に 0） |

- **傾向:** 公式の YAML に書かれた吹き出しは「異議あり」711・「待った」141。検事の「異議あり」が最も多い
  （[../numbers/phrases.md](../numbers/phrases.md#yaml-に書かれた吹き出しshout-と-by)）。
- **推奨:** 並びは「フラッシュ + 効果音 + 吹き出し」の後に、吹き出しの主の台詞。判決の直前に主人公の「待った！」で止める・
  検事が「異議あり！」で抗議するのは、山場の定番（[climax.md](climax.md#判決)）。
