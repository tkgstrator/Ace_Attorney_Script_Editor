# ドキュメント

目的ごとに読むものを並べた目次。初めてなら [はじめてのシナリオ](tutorial.md) から。

## 遊ぶ

```bash
bun install
bun run dev    # プレイヤーとエディタを起動する（表示された URL を開く）
```

プレイヤーではサンプル事件「時計塔の鐘」が始まる。クリックか Enter で進む・X で法廷記録・B でバックログの開閉・
尋問中は ←→ で証言の前後・Z でゆさぶる。章は画面の下の「タイトル」と「章」の選択か `?case=<章の ID>` で選ぶ。
進むたびに状態をブラウザに保存し（オートセーブ）、再読み込みしても同じ場面から続く。最初からやり直すときは「最初から」（オートセーブも消える）。
音量とミュートは画面の下の「章と表示」で変えられる（このブラウザに覚えておく）。

## エディタを使う

`bun run editor`（または `bun run dev`）で、エディタ AAEditor が開く。章をフォームで編集し、右のプレビューでその場で遊べる。
使い方の流れは [はじめてのシナリオ](tutorial.md#6-エディタaaeditorで編集する)。

- 左: 章の選択と「新規」、基本情報・人物・証拠品・フラグ、編ごとのシーン・場所の一覧、章の中の検索
- 中央: 選んだものの入力欄。ステップの追加・並べ替え、入力欄に無い属性は YAML で直接編集
- 右: プレビュー（最初から・状態を保って好きなシーンへ・ステップの「ここから再生」）、整合性チェック、診断
- 保存は ⌘S（Ctrl+S）。`apps/player/cases/` の YAML に書く
