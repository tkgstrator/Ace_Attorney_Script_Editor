# DS 版スクリーンショット（場面別）

元画像（256×384）は `assets/samples/` 直下にある。
`bash tools/ds/split.sh assets/samples assets/samples/ds/unsorted` で上画面・下画面（各 256×192）に分け、
場面ごとのフォルダに振り分けた。ファイル名は撮影時刻なので、同じ名前の上画面と下画面が同じ瞬間の画面。

## 上画面 `top/`

| フォルダ | 場面 | 枚数 |
|---|---|---|
| `dialogue` | 会話。人物＋名前欄＋テキストウィンドウ。黒背景のナレーション、心の声（青字）、中央寄せの心の声も含む | 41 |
| `location-card` | 日時・場所の表示（黒背景に緑字「8月3日 午前10時 地方裁判所 第2法廷」） | 2 |
| `choice` | 選択肢の問いかけ。画面が暗くなり、下に「ぼくのコタエを示そう」の帯 | 5 |
| `evidence-shown` | 話しながら証拠品を見せる（画面左上に証拠品の小窓） | 8 |
| `evidence-added` | 証拠品の入手（証拠品の詳細窓＋「法廷記録にファイルした」） | 3 |
| `testimony` | 証言中。左上に「証言中」の表示。白黒の回想の絵が出ることもある | 16 |
| `cross-exam-start` | 「尋問開始」の文字と、テキストウィンドウに証言のタイトル | 3 |
| `testimony-title` | テキストウィンドウに証言のタイトル（「〜事件の当日、目撃したこと〜」）だけ | 2 |
| `cross-exam` | 尋問中の証言（緑字）。右上に「？？？？？」 | 3 |
| `shout` | 「待った！」「異議あり！」の吹き出し | 3 |
| `gavel` | 木槌を打つ演出 | 2 |
| `wide-shot` | 法廷の全景（テキストなし） | 1 |
| `character-only` | 人物だけが映り、テキストウィンドウがない | 2 |
| `testimony-start` | 「証言開始」の文字と、テキストウィンドウに証言のタイトル | 2 |
| `transition` | 場面の切り替え（横に流れるワイプ） | 1 |
| `title` | タイトル画面（ロゴ）。「新しいエピソードが追加されました」の知らせが重なることもある | 5 |
| `episode-select` | エピソード選択中の上画面（その話の絵） | 3 |

## 下画面 `bottom/`

| フォルダ | 場面 | 枚数 |
|---|---|---|
| `advance` | 通常時。右上に「法廷記録」ボタン、中央に大きな「進む（▶）」ボタン | 42 |
| `idle` | 演出中などで進めない。▶ がなく枠だけ（「法廷記録」ボタンもないことがある） | 14 |
| `choice` | 選択肢のボタン（2 択・3 択） | 5 |
| `cross-exam` | 尋問中。上に「ゆさぶる」「つきつける」、下に前後の証言へ移る ◀ ▶ ボタン | 2 |
| `versus-cutin` | 尋問開始のカットイン（弁護士と検事の顔） | 3 |
| `player-cutin` | 「異議あり！」と同時に出る、弁護士のアップのカットイン | 2 |
| `evidence-present` | 尋問中に証拠品の詳細を開いたところ。上に「つきつける」ボタン | 1 |
| `evidence-list` | 法廷記録・証拠品ファイルの一覧（1 ページ 8 個） | 7 |
| `evidence-detail` | 法廷記録・証拠品の詳細（左右の矢印で送る） | 9 |
| `profile-list` | 法廷記録・人物ファイルの一覧 | 2 |
| `profile-detail` | 法廷記録・人物の詳細（名前と年齢、説明 3 行） | 7 |
| `episode-select` | エピソード選択（「第 2 話 逆転姉妹」、左右の矢印で切り替え、「もどる」「決定」） | 5 |
| `save` | セーブ（「記録 ここまでのクリアデータを保存しますか」はい・いいえ／記録中） | 2 |
| `title-menu` | タイトルのメニュー（「はじめから」「つづきから」「英語」） | 1 |

法廷記録を開いている間（`bottom/evidence-*`・`profile-*`）の上画面は、直前の会話のまま変わらない。
