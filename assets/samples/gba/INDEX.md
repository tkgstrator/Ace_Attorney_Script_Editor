# GBA 版スクリーンショット（場面別）

GBA 版「逆転裁判」（ROM のゲームコード `ASBJ`）の画面。1 画面で 240×160 ドット。どれも第 1 話「初めての逆転」。
元のファイル名 `Gyakuten Saiban (J)(Lightforce)-N.png` を、撮った順の番号 `NN.png` にして場面ごとのフォルダに振り分けた。

| フォルダ | 場面 | 枚数 |
|---|---|---|
| `episode-select` | エピソード選択（法廷の絵に「初めての逆転」と「？？？」のボタン、下に「エピソードを選んでください」） | 1 |
| `location-card` | 日時・場所の表示（黒背景に緑字。テキストウィンドウの中に出る） | 1 |
| `dialogue` | 会話。人物＋名札＋テキストウィンドウ | 3 |
| `choice` | 選択肢。画面全体が暗くなり、上に問いかけ、下に ☞ の付いた選択肢（テキストウィンドウの中に並ぶ） | 3 |
| `evidence-shown` | 話しながら証拠品を見せる（画面左上に証拠品の小窓） | 2 |
| `evidence-added` | 証拠品の入手（画面の上に証拠品の詳細窓＋「法廷記録にファイルした」） | 1 |
| `testimony-title` | テキストウィンドウに証言のタイトル（「〜事件の当日、目撃したこと〜」）だけ | 1 |
| `cross-exam` | 尋問中の証言（緑字）。上の帯の左に「L ゆさぶる」、右に「つきつける R」、その下にライフの「！」5 つ | 1 |
| `evidence-present` | 尋問中に法廷記録を開いたところ。上に証拠品の詳細窓（左右の矢印で送る）、右上に「つきつける」、「A 決定」「B もどる」。テキストウィンドウは証言のまま | 5 |
| `character-only` | 人物だけが映り、テキストウィンドウがない（「異議あり！」の指さし） | 1 |

DS 版（[../ds/INDEX.md](../ds/INDEX.md)）との違い: GBA 版は 1 画面なので、DS 版で下画面にあるものを上に重ねている。

- 法廷記録はボタンが無く、R ボタンで開く（`dialogue/05.png` の台詞）。開くと詳細窓が画面の上の方に重なる
- 「ゆさぶる」「つきつける」は画面の上の帯。L・R ボタンの印が付く
- 選択肢はボタンではなく、テキストウィンドウの中の文字（☞ で選ぶ）
- 証拠品の詳細窓は、法廷記録でも入手のときも同じ（小さい字ではなく、本文と同じ字で書く）
